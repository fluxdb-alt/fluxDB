4. 检查文字是否等于“采纳后”。只有完整只读 SELECT/WITH 才执行，对照结果表。
5. 写语句和故意不完整的负例只看补全，不执行。

如果要检查“有没有串列”，再做一遍：保留 c. / r. 这样的前缀，删除其后的整个残词，再触发一次。此时才检查字段范围；不匹配前缀的字段没出现，本身不代表范围正确。
