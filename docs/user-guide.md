## 1. 启动与主界面

本章介绍 FluxDB 的启动方式，以及主窗口各区域的名称和用途。后续章节中的“连接”“对象”“标签页”等说法，均以本章的界面名称为准。

### 1.1 启动 FluxDB

**从安装包启动**

1. 打开 [最新版本下载页](https://github.com/fluxdb-alt/fluxDB/releases/latest)，下载与系统匹配的安装包。
2. 打开 `.dmg`，把 FluxDB 拖入“应用程序”文件夹。
3. 从“应用程序”或启动台打开 FluxDB。

**从源码启动**

1. 安装 [Rust 工具链](https://rustup.rs)。
2. 克隆项目并进入项目目录：

   ```bash
   git clone https://github.com/fluxdb-alt/fluxDB.git
   cd fluxDB
   ```

3. 启动桌面端：

   ```bash
   cargo run -p fluxdb-desktop
   ```

首次编译耗时通常较长。应用启动后默认显示首页；如果左侧还没有任何连接，可点击左下角“添加连接”开始配置。

### 1.2 主窗口

![FluxDB 主界面](screenshots/manual/home.png)

主窗口分为五个区域：

| 区域 | 位置 | 用途 |
| --- | --- | --- |
| 标题栏与工具栏 | 窗口最上方 | 显示窗口控制按钮、侧边栏开关、首页入口，以及仓库、外观、更新和设置入口 |
| 标签栏 | 工具栏右侧 | 显示已打开的标签页，切换和关闭页面 |
| 连接侧边栏 | 窗口左侧 | 管理连接、分组、数据库、Schema、表和集合，可搜索对象 |
| 工作区 | 窗口中部 | 显示当前标签页的内容：首页、查询编辑器、数据表、设计器、备份、用户权限或设置 |
| 状态栏 | 窗口最下方 | 显示对象数量、当前操作状态和后台任务结果 |

各区域的操作要点如下：

- **连接侧边栏**：单击连接或对象左侧的箭头展开、收起；双击表或集合直接进入数据编辑页。
- **标签栏**：单击标签切换页面；带未保存内容的标签会显示圆点或 `*`，关闭前会要求确认。
- **工作区**：同一时间只显示一个标签页；查询结果、属性面板等可拖动分隔线调整大小。
- **状态栏**：执行查询、备份、导出等操作时，右侧会显示进度或结果，完成后保留最近一次任务状态。

### 1.3 首页

未连接任何数据库时，首页是应用的默认页面；从左侧对象树回到首页可点击工具栏的首页图标。

首页包含三块内容：

1. **连接概览**：显示已保存连接数、当前会话中已连接的连接数和已配置的数据库类型数。
2. **快速开始**：按保存顺序列出连接，显示类型、地址和默认数据库。右侧圆点表示连接状态：空心为未连接，绿色实心为已连接。点击一行可直接打开该连接。
3. **常用操作**：提供“新建连接”“新建查询”“刷新连接树”“设置”四个入口；下方提示文字说明也可以从左侧对象树进入数据编辑页。

### 1.4 标签页

FluxDB 用标签页承载所有功能页面，常见的标签页包括：

- **首页**：连接概览和快速入口。
- **查询编辑器**：SQL 查询、查询结果和历史记录。
- **数据表**：浏览、筛选、编辑表数据。
- **设计器**：新建表、设计现有表。
- **备份列表**：查看和管理数据库备份。
- **用户与权限**：管理账号、角色和授权。
- **Redis / MongoDB 页面**：键浏览、命令工作台、CLI、集合浏览等。
- **设置**：应用配置。

标签页操作：

| 操作 | 方式 |
| --- | --- |
| 切换 | 单击标签 |
| 关闭当前 | 单击标签上的关闭按钮，或按 `⌘W` |
| 关闭其他 / 全部 | 右键标签，选择对应菜单项 |
| 置顶 / 取消置顶 | 右键标签，选择“置顶”或“取消置顶”；置顶标签固定在最前 |
| 复制表名 | 右键标签，选择“复制表名” |
| 重新排序 | 按住标签左右拖动 |

关闭带未保存修改或未提交数据的标签时，应用会先弹出确认框；选择“取消”可留在当前页面继续处理。

### 1.5 状态栏与消息提示

状态栏位于窗口底部，从左到右依次显示：

- **对象数量**：当前标签页或当前选中节点下的对象数量。
- **任务状态**：查询、备份、导出、SQL 文件执行等任务的阶段、成功或失败；完成后保留最近一次结果。

保存成功、复制完成、执行失败等轻量反馈会以消息形式出现在主窗口中，不需要关闭弹窗即可继续操作。出现红色错误提示时，先阅读完整错误信息，再决定是否重试。

### 1.6 界面操作约定

- **单击**：选中对象或标签。
- **双击**：打开数据页（表、集合）或进入编辑状态。
- **右键**：打开当前对象的上下文菜单，菜单项随对象类型变化。
- **箭头**：展开或收起节点；连接未打开时，展开操作会先建立连接。
- **快捷键**：`⌘1` 显示或隐藏连接侧边栏，`⌘Y` 新建查询，`⌘W` 关闭标签，完整列表见[第 13 章](#13-常用快捷键)。
- **只读提示**：连接被设为只读时，写入入口会被禁用或直接拒绝；这是客户端护栏，不替代服务端账号权限。

## 2. 新建数据库连接

本章介绍如何创建、测试和保存数据库连接。连接是对象树、SQL 编辑器和所有数据操作的基础；连接参数填错时，先在本章确认“测试连接”的结果，不要等到执行 SQL 或备份时才发现。

### 2.1 打开“新建连接”窗口

可使用任意一种方式：

- 点击左侧“连接”标题栏右侧的“添加连接”。
- 左侧连接列表为空时，点击列表下方的“添加连接”。
- 在首页快捷操作中点击“新建连接”。

![新建连接](screenshots/manual/new-connection.png)

窗口由三部分组成：

- **左侧类型列表**：按数据库类型选择要创建的连接，上方可输入关键字筛选。
- **右侧参数区**：顶部为“连接信息”“网络与安全”“高级”三个页签，下方显示当前页签的表单。
- **底部按钮**：“测试”验证当前参数能否连通；“保存并连接”保存连接并立即打开。

切换数据库类型时，右侧字段会随类型变化。编辑已有连接时类型锁定，只能修改参数；需要更换类型时，请新建一个连接。

### 2.2 选择数据库类型

当前可实际创建和使用的连接如下：

| 类型 | 主要连接信息 | 默认端口 |
| --- | --- | ---: |
| MySQL | 主机、端口、用户名、密码、数据库、Unix Socket | 3306 |
| MariaDB | 主机、端口、用户名、密码、数据库、Unix Socket | 3306 |
| TiDB | 主机、端口、用户名、密码、数据库、Unix Socket | 4000 |
| PostgreSQL | 主机、端口、用户名、密码、数据库、默认 Schema；也可粘贴 `postgres://` 连接串导入 | 5432 |
| 人大金仓 KingbaseES | 复用 PostgreSQL 连接表单与档案，填写主机、端口、用户名（通常是 `system`）、密码、数据库、默认 Schema；需服务端使用 PG 兼容模式 | 54321 |
| SQL Server | 主机、端口、用户名、密码、默认数据库、Schema、实例名 | 1433 |
| Oracle | 主机、端口、用户名、密码、Service Name 或 SID、默认 Schema、登录身份 | 1521 |
| 达梦 DM8 | 主机、端口、用户名、密码、Schema；高级页可调建连/查询超时与应用名 | 5236 |
| SQLite | 本地数据库文件路径 | 无 |
| Redis | 主机、端口、用户名、密码；单机 / Sentinel / Cluster 共用一组地址，连接时自动识别拓扑；TLS 在“网络与安全”页签配置 | 6379 |
| MongoDB | 主机、端口、用户名、密码、默认库、认证库、认证机制；也可粘贴连接串导入 | 27017 |

数据库类型决定 SQL 方言、可用工具和能力边界。不确定服务端是 MySQL 还是 MariaDB 时，按实际版本选择；MariaDB 的备份工具与 MySQL 不同，详见 [2.11 MariaDB 连接](#211-mariadb-连接)。

### 2.3 填写连接信息

1. 在“名称”中填写便于识别的连接名，例如“本地 MySQL”“测试库（只读）”。名称为必填项。
2. 在“颜色”中选择一个标记色。颜色不参与连接，只用于在连接树和查询上下文中区分环境。
3. 填写“主机”和“端口”。切换类型时端口会自动填入该类型的默认值，服务端改过监听端口时按实际填写。
4. 填写“用户名”和“密码”。密码框默认隐藏内容，可点击右侧眼睛图标临时查看。
5. 按类型填写数据库或默认库。名称和必填项不完整时，保存会直接报错，不创建连接。
6. MySQL / MariaDB / TiDB 需要附加驱动参数时，在“高级 → 连接参数”中填写“URL 参数”，多个参数用 `&` 分隔。
7. 点击底部“测试”，确认无误后再“保存并连接”。

各类型的补充说明：

| 类型 | 填写要点 |
| --- | --- |
| MySQL / MariaDB / TiDB | “数据库”可留空，连接后在对象树中切换；字符集、排序规则与 URL 参数在“高级 → 连接参数”中填写，URL 参数按驱动格式填写，例如 `charset=utf8mb4&parseTime=true`。 |
| PostgreSQL | “数据库”通常填 `postgres` 或业务库；连接后可切换有权限的其他数据库，是否在树中显示由“显示其他数据库”决定。也可粘贴 `postgres://user:pass@host:5432/db?sslmode=require` 导入，支持 `sslmode`、证书路径、`application_name`、`connect_timeout`，以及 `options` 中的 `search_path` / `timezone` / `statement_timeout`；其它参数会明确报错，不会静默丢弃。 |
| SQL Server | 使用 SQL Server 认证；“数据库”为登录后的默认数据库，Schema 留空时连接后读取默认 Schema，读不到时使用 `dbo`。详见 [2.9 SQL Server 连接](#29-sql-server-连接)。 |
| Oracle | 必须二选一填写 Service Name 或 SID。12c 及以上实例通常填 Service Name（例如 `FREEPDB1`）。详见 [2.10 Oracle 连接](#210-oracle-连接)。 |
| 达梦 DM8 | “Schema”留空时使用登录用户同名 Schema。详见 [2.12 达梦 DM8 连接](#212-达梦-dm8-连接)。 |
| SQLite | 点击“文件路径”右侧的选择按钮，选择现有数据库文件；没有默认端口。 |
| Redis | ACL 未启用时“用户名”可以留空；密码按服务端配置填写。主机 / 端口填单机节点、任一 Sentinel 地址或任一集群节点均可，连接时自动识别拓扑。TLS 在“网络与安全”页签配置；连接串导入可识别 `redis://`、`rediss://`、`redis+sentinel://` 与 `redis-cluster://`。Redis 不提供自由参数框，AI Key 前缀在“高级”页签的“AI 访问范围”中填写。 |
| MongoDB | “默认库”决定连接后默认操作的库；“认证库”通常是 `admin`；认证机制可留空由驱动协商。也可粘贴 `mongodb://` 或 `mongodb+srv://` 连接串导入。 |

### 2.4 测试连接并保存

1. 点击底部“测试”。按钮在测试期间不可重复点击，状态行显示“正在测试连接…”。
2. 测试成功时显示“测试连接成功”；失败时显示“测试连接失败”，并且不会保存连接。
3. 测试失败时依次检查：主机和端口、账号密码、目标数据库是否存在、服务端是否允许远程连接、防火墙或安全组、账号的来源地址限制，以及 TLS/SSH 配置是否与服务器一致。
4. 测试通过后点击“保存并连接”。连接会出现在左侧连接树中并自动打开。

也可以跳过测试直接保存，但建议先测试。测试只验证登录和基础连通，不代表账号具备读取对象、导出或备份的权限；这些能力要在后续操作中单独验证。

### 2.5 配置 TLS/SSL

MySQL、MariaDB、TiDB、PostgreSQL、KingbaseES 和 Redis 可在“TLS/SSL”页签中配置加密连接：

1. 勾选“启用 TLS”。取消勾选即明确禁用加密（MySQL 系会下发 `ssl-mode=DISABLED`，不再按驱动默认尝试加密）。未启用时证书、校验与 SSL 模式控件不显示，避免填写后被连接器忽略。
2. 选择 SSL 模式：
   - MySQL、MariaDB、TiDB：`disabled`、`preferred`（默认，不校验证书）、`required`、`verify_ca`、`verify_identity`，与 MySQL 官方 `--ssl-mode` 五档一致。
   - PostgreSQL：`disable`、`prefer`、`require`、`verify-ca`、`verify-full`。
3. 需要双向认证时，分别选择 CA 证书、客户端证书和客户端密钥文件；私钥为 PKCS#8 加密格式时填写“客户端私钥口令”。CA 只在会读取它的校验模式下显示：MySQL 系为 `verify_ca` / `verify_identity`，PostgreSQL 为 `verify-ca` / `verify-full`；其它模式下 CA 不参与连接，因此不显示输入框。
4. PostgreSQL 如证书校验使用的主机名与连接地址不同，填写“SNI / 主机名”。MySQL / MongoDB 驱动不支持独立 SNI，这两个类型不显示该字段。
5. PostgreSQL 用“SSL 模式”控制校验：`verify-ca` 只校验证书链，`verify-full` 同时校验主机名。MySQL 的 `verify_ca` 只校验证书链，`verify_identity` 同时校验主机名；未填 CA 时使用客户端内置根证书，自签证书必须提供 CA 文件，否则连接失败。旧连接里“校验证书”开关为开时会自动迁移为 `verify_ca`。
6. 经 SSH 隧道或代理连接时，拨号目标会被改写为 `127.0.0.1`，证书主机名无法匹配，因此 `verify_identity` 不会出现在下拉中；保存的旧连接也会回落到 `verify_ca`。

SQL Server 的加密选项在同一页签中，以“加密”下拉框提供；Oracle 在该页签中配置 Wallet。SQLite、MongoDB 和 DM8 不使用该页签，打开后会提示当前类型不适用。

### 2.6 配置 SSH 隧道

数据库只能通过跳板机访问时：

1. 打开“SSH 隧道/代理”页签，勾选“启用 SSH 隧道”。未启用时只显示开关和说明，不显示隧道参数。
2. 填写 SSH 主机、SSH 端口、SSH 用户名。
3. 选择认证方式：密码，或私钥文件加可选口令。
4. 按需调整“SSH 调优”中的连接超时与心跳间隔；`0` 表示继承全局超时或不发送心跳。
5. 选择“主机密钥校验”策略：默认严格模式只接受 `~/.ssh/known_hosts`（或用 `SSH_KNOWN_HOSTS` 指定文件）中已记录的密钥；“首次使用自动接受并记录”会在首次连接时把密钥写入 known_hosts；选择“不校验”会跳过主机密钥验证，仅建议在受控网络排障时临时使用。
6. 返回底部点击“测试”，确认隧道和数据库连接均正常。

SSH 隧道对 MySQL、MariaDB、TiDB、PostgreSQL、KingbaseES、Redis、MongoDB、SQL Server、Oracle 和 DM8 提供，且对连接测试、对象浏览、SQL 执行、数据读写与取消操作全部生效；SQLite 为本地文件，打开该页签时会提示不适用。MongoDB 经隧道时只支持单个普通主机（不支持 SRV 与多主机种子列表），并强制直连单个节点。无论选择哪种策略，已记录但发生变更的主机密钥都会被拒绝。

### 2.7 高级设置

“高级”页签顶部是所有类型通用的“只读连接”开关，下面是当前类型的专属选项：

| 类型 | 可配置项 |
| --- | --- |
| MySQL / MariaDB / TiDB | 连接参数（URL 参数、字符集、排序规则）；代理（类型下拉选择 SOCKS5 / HTTP CONNECT，另填主机、端口、可选用户名密码）；建连超时、查询超时、TCP 保活。 |
| PostgreSQL | 建连超时、查询超时、应用名、会话时区、TCP 保活、代理，以及是否显示其他数据库和系统 Schema。 |
| KingbaseES | 与 PostgreSQL 相同（PG 兼容模式），复用同一份连接档案。 |
| Redis | 拓扑自动识别：主机 / 端口可填单机节点、哨兵地址或集群任一节点，连接时先探测是否为集群、再探测是否为哨兵，都不是则按单机连接。“连接行为”中可填 Sentinel 主库名（只监控一个主库时可留空，监控多个主库时必须填写），或勾选“强制按单机连接”跳过探测（仅用于代理 / 端口转发导致误判的场景）；识别为集群后可勾选是否发送 `READONLY` 允许读从节点。“AI 访问范围”的“AI Key 授权前缀”限制 AI 工具可访问的 Key，逗号分隔，留空不限制。旧连接里显式保存的哨兵 / 集群节点仍会生效，编辑时地址回填到主机 / 端口。 |
| SQL Server | 建连超时、查询超时、应用名；命名实例在端口保持默认 `1433` 时经 SQL Browser（UDP 1434）解析实际端口，显式填写端口则以端口为准。 |
| Oracle | 建连超时、查询超时、应用名。 |

MySQL 系的建连超时与查询超时对连接测试、对象浏览和 SQL 执行全部生效；查询超过设定时长时客户端会向服务端发送 `KILL QUERY`，该语句标记为“查询超时”且不返回被打断的结果。建连超时覆盖 TCP 建连、握手与认证。

MySQL 系的代理对测试连接、对象浏览和 SQL 执行全部生效：客户端先与代理完成 SOCKS5（含用户名密码认证）或 HTTP CONNECT（Basic 认证）握手，再把驱动连接转发到数据库。代理参数只在勾选“启用代理”后显示；代理端口必须是 1-65535 的数字，非法值会直接报错，不再静默回落到默认端口。代理不可达、握手失败或认证失败会直接报错，不会静默退回直连。SSH 隧道与代理互斥，同时启用时连接会失败并提示只保留一种。

“高级 → 连接参数”里的“连接字符集”（MySQL / MariaDB / TiDB）会随驱动握手设置会话字符集（例如填 `latin1` 后 `@@character_set_client` 即为 `latin1`），不是仅保存不生效的配置。“排序规则”留空时沿用服务端默认；填写后随握手下发。“Unix Socket”填写后改用本地 socket 拨号，忽略主机与端口；socket 与 SSH 隧道 / 代理不能同时启用。“高级”页签的“会话时区”在建连后设置 `time_zone`（支持 `+08:00` 或 `Asia/Shanghai`），“初始化 SQL”在建连后按分号逐条执行（引号与注释内的分号不拆分），任一条失败都会终止连接。TCP 保活默认关闭；开启后连接改经本地回环转发建立，由客户端设置 `SO_KEEPALIVE`，适用于需要感知中间设备断链的长连接场景。

SQL Server 的查询标签会复用同一会话，因此跨次执行可保持事务、临时表和会话级 `SET` 状态；超时或点击“停止”会关闭该连接以终止服务端执行，结果状态需要重新核对。

开启“只读连接”后，客户端会按数据库类型拦截写入：SQL 按语句解析放行只读查询、事务边界和 `USE`，Redis 按命令白名单放行读命令，MongoDB 的写方法与聚合写阶段（`$out` / `$merge`）直接拒绝；表数据编辑、导入、恢复、建删库/对象等结构性操作一律拒绝。SQLite 同时以驱动级只读方式打开文件。

只读连接是客户端护栏，不替代服务端权限：存储函数副作用、高权限账号等仍可能绕过，生产环境仍应使用只读账号。

不确定时保留默认值即可。

### 2.8 凭据保存说明

连接密码保存在应用数据目录的 `fluxdb.sqlite` 中（`connection_secrets` 表，以 `connection_id` + `secret_kind` 定位，每条含独立的 `nonce` 和 AES-256-GCM `ciphertext`）；连接表不保存密码、密文或凭据引用。默认使用程序内置密钥，不访问系统钥匙串，启动时不会要求输入电脑密码。

可在应用数据目录的 `config.toml` **顶层**手动添加 `connection_secret_key = "<64 位十六进制字符>"` 覆盖默认密钥；软件设置中没有该项，保存普通设置也不会擦除它。应在**首次保存凭据前**设置自定义密钥。已有密文后直接修改或删除该项会导致解密失败，程序会拒绝用新密钥覆盖；请先备份配置与数据库。内置密钥或与数据库同时可读的配置文件只能防止数据库中出现明文，不能防止能读取程序/配置的攻击者解密。

旧凭据不自动迁移、不会被主动删除；升级后请在连接编辑框中重新输入密码并保存一次。

### 2.9 SQL Server 连接

SQL Server 首版使用 SQL Server 认证（用户名 + 密码），不支持 Windows 集成认证。连接参数按以下方式填写：

| 参数 | 说明 |
| --- | --- |
| 主机 / 端口 | 默认端口 `1433`。端口保持 `1433` 且填写实例名时，客户端向 SQL Browser（UDP 1434）查询实例实际端口；已填写非默认端口时直接使用该端口，不再解析实例名。 |
| 数据库 | 登录后的默认数据库。留空表示使用登录账号的默认数据库；连接后可在对象树中切换到其他有权限的数据库。 |
| Schema | 对象的默认 Schema。留空时连接后读取 `SCHEMA_NAME()`，无法读取时使用 `dbo`。生成对象 SQL 时始终显式带 Schema，不能依赖当前连接的默认 Schema。 |
| 实例名 | 可选。例如 `SQLEXPRESS`。解析依赖服务端 SQL Browser 服务与 UDP 1434 可达；SSH 隧道只转发 TCP，命名实例在隧道下必须直接填写实际端口。 |
| 应用名 | 服务端 `APP_NAME()` 中显示的名称，默认 `FluxDB`。 |

“TLS/SSL”页签提供三档加密模式：

- **关闭加密**：不要求全链路加密。TDS 登录包仍会加密，但登录后的业务通信可能是明文；只应在受控网络中使用。
- **要求加密**：要求加密连接，并校验服务端证书。生产环境优先使用该档；需要 CA 或主机名与证书匹配，否则连接会失败。
- **信任服务器证书**：要求加密，但接受自签或不受信任的证书。适合测试环境和无法部署 CA 的内网实例；生产环境应确认这是否符合安全要求。

权限建议：

- 只读查看优先使用最小权限账号，例如授予目标数据库的 `CONNECT`、对业务 Schema 的 `SELECT` 和 `VIEW DEFINITION`；需要编辑数据或结构时再按需授予 `INSERT`、`UPDATE`、`DELETE`、`ALTER` 等权限。
- SQL Server 的元数据可见性受权限控制。账号看不到的对象不会出现在对象树中；`VIEW DEFINITION` 不足时，列、索引、约束、DDL 或触发器信息可能为空或加载失败。这不是对象不存在，应让管理员检查数据库角色和对象级权限。

AI 对 SQL Server 使用与编辑器相同的 T-SQL 方言：只读查询、`db.describe_object` 和只读页面上下文可用；写语句需要人工审批。只读入口除客户端分类外，还会把语句放进事务并在结束后回滚，写操作不会被提交。执行计划使用 `SET SHOWPLAN_ALL` 在独立会话生成，不会执行被解释的语句。`xp_cmdshell`、`OPENROWSET`、`sys.sql_logins`、`sys.dm_exec_sessions` 等越权能力与系统视图会被拒绝或降级为需授权。

SQL Server 的存储过程和函数会出现在对象树对应分组中。左键点击对象可查看只读 DDL；读取定义需要账号具备相应 `VIEW DEFINITION` 权限，否则会显示权限错误。
- `sysadmin` 或 `db_owner` 能看到全部对象并执行多数操作，但不应作为日常桌面连接的默认账号。备份、恢复和跨库操作需要的权限高于普通浏览，应按任务单独授权。
- 应用当前不会把密码写入普通连接配置、日志或 AI 上下文；保存连接前请确认只使用测试库或已授权账号。

备份与导入边界：

- 表数据导入已支持，可通过文件解析、列映射和批量参数绑定写入表。identity 列在导入时会按列信息使用 `IDENTITY_INSERT`；清空模式使用 `TRUNCATE TABLE`，被外键引用时会被服务端拒绝，不会静默改为 `DELETE`。
- 表级备份和恢复仍在接入中，当前会明确提示不支持，不会用 `BACKUP DATABASE` 冒充表级备份。数据库级物理备份涉及服务端文件路径、权限和恢复覆盖策略，需在独立功能中处理。
- “导出数据”仍可对表数据进行导出；首次打开导出窗口时，如果预览接口返回不支持，导出按钮可能无法继续，请以当前界面的错误提示为准。

### 2.10 Oracle 连接

Oracle 的“Schema”就是“用户”。对象树先显示当前容器（PDB），再按 Schema 组织，没有 MySQL 那样的“库 → 表”两层。连接参数按以下方式填写：

| 参数 | 说明 |
| --- | --- |
| 主机 / 端口 | 默认端口 `1521`。填写监听器实际监听的主机和端口。 |
| 连接方式 | 在 Service Name 与 SID 之间二选一，二者不能混用。12c 及以上的多租户实例通常用 Service Name，并需指明要进入的 PDB（例如 `FREEPDB1`）。 |
| 用户名 / 密码 | 登录账号。未加双引号创建的账号和对象名在 Oracle 中一律大写折叠，界面上按大写显示；需要用引号保留大小写时，对象名本身已含大小写。 |
| 登录身份 | 默认普通连接。`SYSDBA` / `SYSOPER` 必须显式选择，不会从用户名（例如 `sys`）自动推断。 |
| 建连超时 | 可选，默认 8 秒，覆盖 DNS / TCP / TLS 握手；填 `0` 不设限。 |
| 默认 Schema | 可选。连接后执行 `ALTER SESSION SET CURRENT_SCHEMA`，只影响未限定名的解析，**不增加任何权限**。 |
| Wallet | 可选。填写本地 Wallet 目录；目录本身不是凭据，但 Wallet 口令按同类凭据处理，不会明文落盘。 |

对象定位使用 `"OWNER"."TABLE"` 两段式名称：Oracle 不区分“数据库.表”，必须带上所属 Schema。未加引号的标识符按大写处理，因此 `select * from orders` 实际访问的是 `ORDERS`；对象名含小写或特殊字符时必须加双引号。

数据展示与编辑需要注意：

- `DATE` 类型在 Oracle 中自带时分秒，界面上按日期时间处理，不要当成纯日期。
- `NUMBER` 按精确数值读取，不会转成浮点数后再显示，避免大整数和小数精度丢失。
- `CLOB` / `BLOB` 只做有界预览，不整块载入内存。字符 LOB 超过 4000 字符时，格子与详情都标为「仅预览」；打开详情会在后台自动读取完整值（上限 8 MiB），读到后才能编辑。带预览的单元格不能就地编辑，导出、复制、导入与逻辑备份会拒绝半截值，避免用片段覆盖完整数据。
- 分页使用 12c 及以上的 `OFFSET … FETCH NEXT`，列排序会补上唯一键以保证翻页稳定；没有唯一键的表，翻页顺序只能按实际执行计划确定。

导出与备份边界：

- “导出数据”是本机逻辑导出：导出 DDL 加逐页读取的数据，不是服务器端 Data Pump 备份，也不是数据库级灾难恢复方案。
- 每页是独立查询，跨页不共享同一个一致性快照；导出期间有并发写入时，导出结果可能包含不同时点的数据。需要严格一致的快照应使用 Oracle 自身的 Data Pump 或闪回能力。
- Data Pump 的 `DIRECTORY` 是服务器端路径，桌面端无法直接写入，因此当前不提供“一键备份”按钮。

AI 对 Oracle 使用 `OracleDialect` 解析，只读判定比 MySQL 类数据库更严格：`SELECT … FOR UPDATE`、`seq.NEXTVAL`、`utl_*` / `dbms_*` 包成员、以及通过同义词、视图或 `@dblink` 间接访问的对象都不会被判为只读，需要人工审批；`EXPLAIN PLAN FOR` 会写入计划表，同样按写操作处理。提交期间断网时结果未知，不会自动重放写语句。

### 2.11 MariaDB 连接

MariaDB 的连接信息与 MySQL 基本一致：主机、端口（默认 `3306`）、用户名、密码和默认数据库。FluxDB 会按连接类型自动切换方言和工具，不需要手工改 SQL。

需要注意的差异：

- **账号 DDL**：MariaDB 新建用户默认使用 `mysql_native_password`，认证插件按 `IDENTIFIED VIA … USING PASSWORD(…)` 生成；角色是不带 host 的账号。用户与权限面板会按 MariaDB 语法生成语句。
- **备份工具**：优先使用 MariaDB 客户端工具（`mariadb-dump`）。只有 MySQL 客户端时可能因版本不兼容失败；可把 MariaDB 客户端加入系统 PATH，或在“设置” → “数据” → “MySQL 客户端”中检测本机 MariaDB 安装（该页保存按钮不可用，手工路径仅对当前会话有效）。
- **函数与类型**：大部分函数与 MySQL 兼容，但 JSON 处理、窗口函数细节和部分系统表不同；跨库迁移 SQL 时先在测试库验证。

### 2.12 达梦 DM8 连接

达梦以“实例 + Schema”组织对象，没有独立的数据库层级，因此对象树按 Schema 展示。DM8 使用独立的连接档案，不与其他类型共用 MySQL 参数。

| 参数 | 说明 |
| --- | --- |
| 主机 / 端口 | 默认端口 `5236`。填写数据库实例实际监听的主机和端口。 |
| 用户名 / 密码 | 默认用户名为 `SYSDBA`。日常使用建议改用业务账号，不要长期用管理账号连接。 |
| 说明 | 达梦的实例名由服务端监听地址决定，客户端连接不单独传实例名；界面不再提供该字段。 |
| Schema | 默认 Schema。留空时使用登录用户同名 Schema；只影响未限定名的解析，不增加任何权限。 |
| 高级 | 建连超时（默认 5 秒）、查询超时（0 表示不设限）、应用名（DM 会话可见）。字符集由驱动握手自动检测，界面不提供。 |

对象定位使用 `"SCHEMA"."TABLE"` 两段式名称。未加引号的标识符按服务端规则折叠，对象名含小写或特殊字符时必须加双引号。

DM8 当前不提供触发器设计页签，新建表时只能配置表、列、索引等基础结构；需要创建触发器时，在 SQL 编辑器中执行 DDL。

## 3. 管理连接与数据库

本章介绍如何用左侧连接树管理连接、分组和数据库对象。连接树是进入所有功能的起点；树中显示的内容以当前账号的服务端权限为准。

### 3.1 连接树的结构

![连接与对象树](screenshots/manual/mysql-tree.png)

连接树按数据库类型分层显示：

| 类型 | 层级 |
| --- | --- |
| MySQL / MariaDB / TiDB / SQLite | 连接 → 数据库 → 表、视图、函数、存储过程等分组 |
| PostgreSQL / KingbaseES / SQL Server / 达梦 DM8 | 连接 → 数据库 → Schema → 对象分组 |
| Oracle | 连接 → 容器（PDB）→ Schema → 表、视图 |
| Redis | 连接 → 逻辑库（`0`～`15`），Key 在数据库页签中查看 |
| MongoDB | 连接 → 数据库 → 集合 |

- 单击节点选中；双击表或集合进入数据页；右键打开该节点的上下文菜单。Redis Key 在数据库页的键列表中查看，单击即可加载右侧详情。
- Redis 逻辑库单击打开键浏览器，双击打开 Redis Workbench。
- 节点前的箭头展开或收起；连接未打开时，展开会先建立连接。
- 连接名称前的色块是创建连接时选择的颜色，用于区分环境。
- 标题栏右侧依次是“新建分组”“刷新”“添加连接”三个按钮，刷新只重新加载连接树，不跟随当前标签页。

“搜索表”输入框按名称过滤已加载的表、视图、函数、存储过程和集合。未连接或尚未展开的连接不会出现在结果中，搜索前先展开目标连接。

### 3.2 打开、关闭和刷新连接

右键连接可执行：

| 菜单项 | 说明 |
| --- | --- |
| 打开连接 / 关闭连接 | 建立或释放当前连接会话；关闭时如果该连接下还有标签页，会先弹出确认。 |
| 新建查询 | 打开查询编辑器，先选择连接和数据库作用域；MongoDB 连接不提供。 |
| 用户与权限 | 打开该连接的用户和权限管理页；MySQL、MariaDB、TiDB、PostgreSQL、KingbaseES、SQL Server、Oracle、DM8 可用（KingbaseES 沿用 PostgreSQL 实现，尚未单独回归），SQLite 显示为不可用。 |
| 执行 SQL 文件 | 选择本地 SQL 文件并在该连接上执行，仅 SQL 类型连接提供。 |
| 新建数据库 | 在服务端创建数据库；Redis 不提供。 |
| 移至分组 / 取消分组 | 把连接放入分组或移回顶层。 |
| 刷新 | 重新读取数据库和对象树。 |
| 选择显示数据库 | 只显示勾选的数据库，减少对象树中的干扰项；仅 SQL 类型连接提供。 |
| 编辑连接 | 修改连接参数并重新测试、保存；数据库类型不可修改。 |
| 复制连接 | 以当前配置创建副本，名称自动加上“副本”。 |
| 删除连接 | 删除本地保存的连接和凭据；不会删除服务端数据库。 |

MongoDB 连接不显示新建查询、用户与权限、执行 SQL 文件和选择显示数据库，改为“显示连接信息”和置灰的“查看性能指标”。

> 删除连接不可撤销，但不会影响服务端数据。删除前确认没有其他标签页仍在使用该连接。

### 3.3 使用连接分组

1. 点击“连接”标题栏中的新建分组按钮，输入分组名称。
2. 右键连接，选择“移至分组”，再选择目标分组。
3. 需要移出时，右键连接选择“取消分组”。
4. 右键分组可“新建连接”“重命名”或“删除分组”。

删除分组只移除分组本身，组内连接会回到顶层，连接配置和凭据不受影响。建议按环境或项目分组，例如“本地”“测试”“生产”。

### 3.4 管理数据库节点

右键数据库节点，常用操作随连接类型变化。

SQL 类型连接：

- 打开或关闭数据库。
- 置顶或取消置顶；置顶只在当前应用会话内生效。
- 新建表、新建 schema（PostgreSQL、KingbaseES、SQL Server、DM8、Oracle）、执行 SQL 文件、备份。
- 新建查询、在数据库中查找。
- 刷新或删除数据库。

Redis 连接：

- 打开或关闭数据库。
- 打开 Redis Workbench、Redis CLI、Pub/Sub。
- 刷新。

MongoDB 连接：

- 打开或关闭数据库。
- 创建集合、打开命令行终端或命令工作台。
- 刷新或删除数据库。

PostgreSQL、KingbaseES、SQL Server、DM8 和 Oracle 的 Schema 节点还有独立菜单，可新建查询、新建表、设置默认 schema 或刷新。

“设置默认数据库”和“设置默认 schema”当前只提示入口已就绪，不会保存默认值。需要固定默认库时，打开“编辑连接”，在“数据库”中填写；新建查询后也可以在编辑器顶部切换作用域。

> 删除数据库会删除服务端真实数据，且不可撤销。请核对连接、数据库名和备份状态后再确认。

### 3.5 管理标签页

右键标签页可执行：

| 操作 | 说明 |
| --- | --- |
| 复制表名 | 复制当前标签页对应的表或集合名称。 |
| 置顶 / 取消置顶 | 置顶标签固定在最前，不会被新标签挤走。 |
| 关闭 | 关闭当前标签页。 |
| 关闭其他 | 关闭除当前标签页外的其他标签页。 |
| 关闭全部 | 关闭当前作用域内的全部标签页。 |

标签可以按住左右拖动重新排序；置顶标签和非置顶标签分属两个区域。包含未保存内容或未提交修改的页面在关闭前会给出确认提示。

## 4. 使用 SQL 编辑器

本章介绍查询页的创建、编写、执行和结果查看。编辑器按当前连接的方言处理关键字、补全、格式化与执行计划，不需要手工切换模式。

![SQL 编辑器](screenshots/manual/mysql-query.png)

### 4.1 新建查询

可使用以下方式：

- 右键 SQL 类型连接、数据库或 Schema，选择“新建查询”。
- 点击首页快捷操作中的“新建查询”。
- 按 `⌘Y`。

### 4.2 选择查询作用域

新建查询时，如果当前没有明确的连接或数据库，FluxDB 会打开作用域选择窗口：

1. 在左侧选择连接；未连接的连接会显示连接入口，连接后再列出数据库。
2. 在右侧选择数据库。PostgreSQL 默认 `postgres`，KingbaseES 默认 `test`，SQLite 默认 `main`，DM8 默认 `DAMENG`，Redis 默认 `db0`。
3. 点击数据库条目进入编辑器。

编辑器顶部显示当前连接和数据库，作用域在创建后固定；需要换库时新建查询，或在 SQL 中显式限定库名。执行前请核对顶部作用域，避免把语句发到错误环境。

### 4.3 编写和补全 SQL

- 输入 SQL 关键字、表名或字段名时，编辑器会提供补全建议。
- 按 `Control+Space` 主动触发补全。
- 光标停在函数括号内（如 `COUNT(`）时，编辑器会显示函数参数提示并高亮当前参数。参数提示只覆盖连接方言的内置函数，自定义函数不显示。
- 按 `⌘/` 切换当前行或选中行的行注释。
- 工具栏“美化 SQL”优先格式化选区；没有选区时格式化全文。
- 工具栏“压缩 SQL”优先压缩选区；没有选区时压缩全文。
- 工具栏的换行按钮在“自动换行”和“不换行”之间切换，并写入编辑器设置。
- “查询创建工具”和“代码段”两个按钮当前为置灰占位，暂不可用。

### 4.4 执行 SQL

1. 只执行特定 SQL 时，选中完整语句。
2. 未选中时，把光标放在要执行的语句中。
3. 点击工具栏“运行”，或按 `⌘Enter`。

执行优先级为：完整选中语句 → 选中文本 → 光标所在语句。无法确定语句时，应用会提示先选中 SQL 或把光标放入语句。

编辑器会在每条语句上方显示 `Run` 和 `Select` 两个快捷入口，直接执行该条语句：

- `Run`：执行当前语句，写语句会真实提交。
- `Select`：按查询语义执行，适合只读语句；执行流程与 `Run` 相同，不会额外拦截写语句，是否只读取决于连接和账号权限。

其他执行方式：

| 操作 | macOS 快捷键 | 说明 |
| --- | --- | --- |
| 执行 | `⌘Enter` | 执行选中文本或光标所在语句 |
| 执行当前语句 | `⌘R` | 编辑器聚焦时执行选区；无选区时执行光标所在语句；会覆盖全局刷新快捷键 |
| Select 模式 | `⌘⇧R` | 以 Select 模式执行选区或光标所在语句 |
| 执行计划 | `⌘⇧E` | 对选区或光标所在语句执行 Explain；无法解释时给出提示 |
| 停止 | 工具栏“停止” | 请求取消正在执行的查询，仅执行期间可用 |

默认会对 `DROP`、`TRUNCATE` 以及不带 `WHERE` 的 `UPDATE` / `DELETE` 弹出确认；可在“设置” → “编辑器”中调整确认开关和危险操作清单。

取消请求发出后，服务端可能已经执行完成或只完成一部分；应重新查询数据确认状态，不要直接重复执行写语句。

### 4.5 使用运行参数

SQL 中使用命名参数或位置参数时，运行前会出现“运行参数”窗口：

- 命名参数：`:user_id`、`:status`。
- 位置参数：`?`，按出现顺序编号。

填写方式：

1. 在“逐个输入”中分别填写每个参数；或切换到“数组输入”批量提供值。
2. 点击“应用并运行”。
3. 参数会转换为 SQL 字面量并替换进本次执行文本。执行高风险语句前，请在结果区或执行记录中再次核对实际执行的 SQL。

字符串参数会被转义为 SQL 字面量，但这不改变账号权限；仍需避免把不可信输入直接拼进 SQL。

### 4.6 查看查询结果

每次执行的语句会按顺序生成“结果 1”“结果 2”等页签，“执行摘要”页签汇总本次执行：

| 摘要列 | 说明 |
| --- | --- |
| 语句 | 本次执行的 SQL 文本。 |
| 类型 | 语句类型或执行模式。 |
| 返回行 | 查询返回的行数。 |
| 影响行 | 写语句影响的行数。 |
| 耗时 | 单条语句的执行耗时。 |

结果区支持：

- 数据表横向滚动、分页和每页行数切换。
- 列头筛选、排序和字段显示控制。
- 工具栏“刷新”重新执行当前语句，“收起结果”折叠结果区。
- 结果在下方或右侧显示，拖动分隔线调整大小；工具栏最右侧按钮可切换位置。
- 结果页右上显示“可编辑”时，表示这是一条可定位到单表的 `SELECT`（没有 `DISTINCT`、`JOIN`、`GROUP BY`、`UNION` 等），可以按第 5 章的方式修改并提交；其他查询结果只读。

查询失败时，结果区显示错误信息、出错 SQL，以及“复制错误”“重试”和“用 AI 修复”。“用 AI 修复”需要先在设置中配置 AI 模型。

### 4.7 保存、打开与历史

工具栏右侧按钮：

| 按钮 | 说明 |
| --- | --- |
| 打开本地 SQL 文件 | 在新标签页打开 `.sql` 文件，只加载内容，不自动执行。 |
| 保存 / `⌘S` | 首次保存时选择“保存到本地文件”或“保存到连接中”；之后按 `⌘S` 直接保存到同一目标。 |
| 历史记录 / `⌘⇧H` | 搜索并重新打开历史 SQL。 |

保存到连接中时需要填写查询名称，查询会出现在对应数据库（或 Schema）的“查询”分组中；同名保存会覆盖原查询。保存到本地时使用系统文件面板，默认使用 `.sql` 扩展名。

历史记录会保留执行过的 SQL，可能包含业务数据和敏感字面量，请按本机数据安全策略清理。

## 5. 浏览、筛选和编辑表数据

![数据浏览与编辑](screenshots/manual/mysql-table-data.png)

### 5.1 打开数据表

1. 在连接树中展开连接、数据库和表节点。
2. 双击表，或右键表选择“查看数据”。
3. 等待数据加载完成。

底部显示分页、行数和加载状态。切换页码或刷新前，如果当前有未提交修改，应用会先要求确认，避免直接丢失本地修改。

### 5.2 搜索、筛选和排序

- **搜索**：点击工具栏“搜索”，或按 `⌘F`，在当前数据页中查找内容；搜索栏显示“当前/总数”匹配，可点“下一个”逐条跳转，点击匹配计数可切换全部匹配的高亮。
- **筛选 & 排序**：点击工具栏“筛选 & 排序”展开面板。面板有“表单”和“输入”两种模式：
  - **表单**：逐条添加字段、运算符和值，可继续“新增条件”；支持等于、不等于、包含、不包含、开头/结尾、介于、在列表、为空等运算符。
  - **输入**：直接填写 `WHERE` 与 `ORDER BY` 条件；当前数据源不支持 SQL 条件表达式时会提示。
  - 调整后点击“应用筛选 & 排序”。面板底部的 SQL 预览会显示最终生成的条件。
- **单元格快捷筛选**：右键单元格，在“筛选”子菜单中选择“字段 = 值”“字段 != 值”“字段类似值”“字段不类似值”“字段 < 值”“字段 > 值”，或“移除当前字段筛选”。
- **单元格快捷排序**：右键单元格，在“排序”子菜单中选择“升序排序”“降序排序”或“移除当前字段排序”。
- **字段筛选**：控制表格中显示哪些字段，适合字段较多的表。
- **移除所有筛选 & 排序**：从单元格右键菜单一键恢复默认数据范围。

筛选条件会转换为数据库方言对应的 SQL。生产环境中使用复杂条件时，建议先检查 SQL 预览。切换页码、刷新或改变筛选排序前，如果存在未提交的单元格修改，应用会先要求确认。

### 5.3 编辑单元格

当结果区显示“可编辑”时：

1. 双击单元格进入编辑。二进制字段不能就地编辑，需使用“上传替换”或右键“设置为 NULL”。
2. 右键单元格可执行：
   - “设置为空白字符串”或“设置为 NULL”；
   - “删除记录”或“删除选中行”；
   - 复制当前单元格、复制字段名称、粘贴；
   - “筛选”“排序”子菜单；
   - “移除所有筛选 & 排序”。
3. 修改只会先进入本地待提交状态，不会立即写入数据库。
4. 查看底部待修改数量和 SQL 预览。
5. 点击“提交更改”写入数据库；点击“取消更改”放弃本地修改并重新加载数据。

超大字段只加载了预览时，复制会被禁用并提示打开单元格详情查看或保存完整内容，避免把片段当成真实值带走。

如果查询结果不能可靠定位源表或记录，编辑能力会被禁用。不要通过绕过主键或唯一标识的方式强行更新数据。

### 5.3.1 大字段的显示与查看

单个字段超过 64 KiB（大文本、JSON、二进制）时不会整份留在内存里，也不会让这一行消失：

- 表格与查询结果里显示有界预览，并注明只是片段；详情面板给出完整字节数。
- 进入单元格详情后按块加载（每块约 256 KiB），点“读取更多”继续往下翻，不会一次读出整份内容；读取期间该按钮变成转圈并暂停响应，状态区同样显示转圈，读完再恢复。
- “下载”会把完整内容流式写入你选择的位置（不会把值复制到剪贴板），二进制字段的“下载”同样先选路径。
- 单元格操作统一放在详情面板“值”标题行，且都用图标按钮（悬停显示名称），大字段与普通字段位置一致：下载图标＝把完整内容存成文件，上传图标＝用本地文件整值替换，双下箭头＝继续读取下一段。
- 总量、已读窗口与加载状态紧随“值”标题排在同一行：总量是浅底小标签，窗口范围是灰字（过长省略，悬停看完整范围），中间细进度轨显示已读部分占全文的比例，末尾色点＋短词表示“仅片段 / 加载中 / 已到底 / 失败”。不再单独占一行。
- 大字段不提供“复制整值”和就地编辑：完整内容需要按块查看或另行下载，避免把上百 MB 文本塞进输入框。
- 页容量按行数控制，不再设置整页 16 MiB 驻留预算；多个小字段合计超过 16 MiB 也会正常收进本页。单格外置失败时查询或导出明确失败，不返回缺行却看似成功的结果。
- 超大字段内容存于本地临时目录（每份结果最多 256 MiB），关闭标签、刷新数据或断开连接即清理。
- 二进制字段（`BLOB`/`VARBINARY`/`bytea`/`RAW`/`IMAGE` 等）在 MySQL、PostgreSQL、SQLite、SQL Server 的表格里只显示“类型 + 字节数 + 十六进制前缀”，正文不会整份读进结果页；要看完整内容请进详情面板按块读取或下载。达梦暂按原值返回，超过 64 KiB 时同样外置成内容引用。
- 各数据库走同一套单格外置规则：单格超过 64 KiB 先外置成内容引用，整页不再按累计字节数截断。SQL Server 与达梦不会再因为页预算直接丢掉整行。

“上传替换”按文件大小走两条路径：

- 小于 16 MiB 的文件一次读入内存、用一条语句写入，这是小文件最快的路径。
- 16 MiB 及以上的文件先把内容流式落到本地暂存目录，提交时按 16 MiB 分块追加到字段：进程内存峰值固定在分块大小，不会随文件变大而上涨，界面也不会因为要把几百 MB 读进内存而卡住。
- 暂存总量受单个归属 256 MiB 配额约束，超过时直接提示并放弃，不会写半份。
- 是否支持分块追加因数据库而异。MySQL、MariaDB、TiDB、SQLite、PostgreSQL、SQL Server 支持；Oracle、达梦暂不支持，超过阈值的文件会被拒绝并提示改用较小的文件。
- 追加写法在 MySQL/SQLite/PostgreSQL 上会重写整个字段（代价随已写长度增长），所以分块不宜过小；16 MiB 是在速度和内存之间取的折中值。
- 提交前放弃改动、关闭标签或刷新数据，暂存内容会一并清理。

“上传替换”同时适用于大文本字段（`TEXT`/`LONGTEXT`/`CLOB`/`nvarchar(max)` 等无长度上限的文本类型）和二进制字段，入口与阈值完全一致。文本字段另外有三条约束：

- 上传后单元格先显示为 `LONGTEXT…（共 50.0 MB）` 这类占位值，正文在提交前存在本地暂存区；详情面板可直接按块读出你刚选的文件，确认无误再提交。
- 占位值不是正文：不提供复制、就地编辑与导出，避免把「类型 + 大小」当成数据带走。
- 文件必须是合法 UTF-8，否则直接拒绝并提示，不做替换字符之类的隐式转换。
- 分块追加会回退到 UTF-8 字符边界再写入，因此多字节字符跨块也不会被截断。
- `JSON`/`JSONB` 字段不提供上传替换：分块追加无法保证每一块都是合法 JSON，整值写坏后数据库也读不回来。

### 5.4 新增、克隆和删除行

右键行号或记录区域，可以：

- **行详情**：打开记录详情，逐字段查看完整值。
- **复制**：复制为 JSON、TSV；表对象可用时还可复制为 `INSERT`、不含主键的 `INSERT` 或 `UPDATE` 语句。
- **新增一行**：在当前页追加一条待提交记录。
- **克隆为新行**：以当前行内容为模板复制一条待提交记录。
- **删除行 / 删除选中行**：标记删除；选择多行时按选中范围处理。
- **导出**：按 CSV、`INSERT`、JSON 或 Markdown 导出当前行或选中行。

新增、修改和删除都会统一进入待提交状态，不会立刻写入数据库。提交前可查看生成的 SQL，确认删除条件不会误命中其他记录后再提交。

### 5.5 查看表属性

点击数据工具栏“表属性”，右侧打开表结构面板。面板分为“字段”“索引”“外键”“触发器”“DDL”五个页签，切换页签时按需加载对应内容。再次点击“表属性”或面板右上角关闭按钮可收起。

### 5.6 导入数据

1. 打开目标表的数据页。
2. 点击工具栏“导入”。
3. 在导入窗口点击“选择文件”，选择 TXT、CSV、JSON 或 XML 文件。
4. 确认解析选项：文件编码（UTF-8 / GB18030）、“首行是表头”“去除首尾空白”“空值按 NULL”。改动后会重新解析预览。
5. 检查字段映射：左侧为源字段，右侧选择目标字段；不需要导入的源字段选择“跳过”。
6. 选择导入模式：
   - **追加**：保留现有数据，把文件内容追加到末尾。
   - **清空后导入**：先删除目标表全部数据，再写入文件内容。
7. 至少映射一个目标字段后，点击“开始导入”，在“日志”页签查看各阶段结果和已导入行数。

“目标方式”当前只支持“导入现有表”；“创建新表”显示为禁用预留项。

选择“清空后导入”时注意：

- PostgreSQL、SQLite 的清空与写入在同一事务内，失败会自动回滚。
- 其他数据库的清空操作无法回滚，执行前先确认目标表数据已备份。

同一时间只能运行一个表数据导入任务；任务执行中不能清除日志。预览只展示前 50 行，实际导入会处理完整文件。

### 5.7 当前未开放入口

数据工具栏中的“数据分析”“数据生成”点击后暂无动作，表示当前版本尚未接入，不影响已有的数据浏览、编辑、导入和导出功能。

## 6. 查看和设计表结构

### 6.1 查看结构

打开表的数据页，点击工具栏“表属性”，右侧结构面板包含五个页签：

| 页签 | 内容 |
| --- | --- |
| 字段 | 列名、类型、是否可空、注释 |
| 索引 | 索引名、包含字段、索引类型；主键显示 `PK`，唯一索引显示 `UNIQUE` |
| 外键 | 约束名、本表字段、引用目标（`Schema.表.字段`） |
| 触发器 | 触发器名、触发时机、触发事件 |
| DDL | 当前表的建表语句，只读；可“复制 DDL”或切换自动换行 |

面板内容只读，不会修改表结构。切换页签时按需加载对应元数据；再次点击“表属性”或面板右上角关闭按钮可收起。

### 6.2 新建表

1. 右键数据库或 Schema，选择“新建表”。PostgreSQL、SQL Server、Oracle、达梦等按 Schema 组织对象，应在目标 Schema 上新建。
2. 填写表名，可补充表注释。
3. 在“字段”页点击“添加字段”，逐列设置：
   - 列名、类型、长度或精度；
   - 是否可空、默认值、注释；
   - 主键、自增/标识列；
   - 字符集、排序规则、无符号、补零等类型相关选项；
   - `ENUM` / `SET` 成员值（按数据库支持情况显示）。
4. 按需切换“索引”“外键”“检查”“触发器”页签补充约束。
5. “选项”和“分区”页签主要面向 MySQL、MariaDB、TiDB：
   - 存储引擎、字符集、排序规则、行格式、表空间等；
   - 分区方式、分区表达式或分区 SQL；
   - 其他数据库会显示“不支持”提示；达梦的分区页签为只读说明。
6. 打开“SQL 预览”检查将执行的建表语句。
7. 点击底部“保存”执行建表。表名为空或没有字段时保存按钮不可用，按提示补齐后再保存。

![新建表](screenshots/manual/mysql-create-table.png)

PostgreSQL 触发器需要引用已存在的函数；不能直接使用 MySQL 风格的行内触发器体。达梦的“触发器”页签不提供“添加触发器”按钮。

### 6.3 设计现有表

![设计表](screenshots/manual/mysql-table-design.png)

1. 右键表，选择“设计表”。应用会读取现有表结构并在后台打开设计页。
2. 在“字段”“索引”“外键”“检查”“触发器”页签修改结构；MySQL 系还可调整“选项”和“分区”。
3. 切换“DDL”页签查看当前表定义，或打开“SQL 预览”核对将执行的 `ALTER` 语句。
4. 点击底部“保存”执行变更。

设计页保存的是结构变更，不会自动提交表数据页里尚未提交的单元格修改。

> **注意**：结构变更可能锁表、重建表或丢失数据。大表和生产库应在维护窗口操作，并提前验证备份可用。

> **提示**：部分数据库不支持某些变更类型，或需要在 SQL 预览中确认生成语句后再执行。预览与最终执行不一致时，以数据库返回的错误为准，不要连续重试。

### 6.4 表的其他右键操作

表右键菜单按顺序提供：

| 菜单项 | 作用 |
| --- | --- |
| 置顶 / 取消置顶 | 把表固定在连接树前部；仅当前会话有效 |
| 复制名称 | 复制表名到剪贴板 |
| 查看数据 | 打开表数据页 |
| 关联 ER | 以该表为中心打开 ER 图，可在工具栏调整展开深度 |
| 设计表 | 打开结构设计页 |
| 新建表 | 在当前数据库或 Schema 中新建表 |
| 刷新 | 刷新已打开的数据页和表属性；有未提交修改时先确认 |
| 重命名 | 修改表名，执行前显示 SQL 预览 |
| 复制表 | 输入新表名，选择“仅结构”或“结构和数据”创建副本 |
| 复制表结构 | 把建表 DDL 复制到剪贴板 |
| 备份 | 打开备份窗口并预选当前表 |
| 导入数据 | 打开表数据导入向导 |
| 管理组 | 把表加入业务组或从组中移出 |
| 导出 | 子菜单包含“导出数据库”和“导出数据” |
| 删除表 | 删除表结构和数据 |
| 清空表 | 删除表中全部记录 |

“删除表”和“清空表”都会打开危险操作确认窗口：

- 窗口内显示将执行的 SQL，并要求勾选“我了解此操作是永久性的且无法撤销”。
- MySQL、MariaDB、TiDB 可设置外键检查方式：默认、启用或禁用。
- PostgreSQL 清空表时可选择是否重置自增序列；默认不重置。
- 删除表会移除表结构和数据；清空表保留表结构，但删除全部记录。

确认前请完整阅读 SQL 和影响范围，不要仅凭按钮位置连续确认。

### 6.5 查看 ER 关系图

打开方式：

- 展开连接和数据库，单击对象分组中的“ER 图”，打开整库关系图。
- 右键单张表，选择“关联 ER”，以该表为中心打开；工具栏可调整展开深度并返回全库。

画布操作：

1. 拖动表节点调整位置；拖动空白区域平移画布。
2. 滚轮缩放，或使用工具栏的减号、百分比、加号和“适配当前范围”。
3. 工具栏还提供“回到起点”“按关系排列（保留手动位置）”“重置手动位置并排列”和“撤销上次排列”。
4. 连线表示数据库外键或本地逻辑关系；字段较多时可在节点内滚动查看。

关系面板：

1. 点击工具栏右侧面板按钮，打开“本地逻辑关系”。
2. 可新建本地逻辑关系，或确认、拒绝待确认的关系。
3. 删除只影响本地逻辑关系，不修改数据库外键；最近删除的关系可在面板内恢复，恢复后仍需确认。

导出与导入：

- “导出”可生成 JSON、DBML、Mermaid 或 SVG 文件。
- 导入 ER JSON 只应用同名表的布局，不会修改数据库结构或关系；连接或数据库不匹配时仅允许预览。

![ER 关系图](screenshots/manual/mysql-er.png)

关系图读取元数据，逻辑关系单独保存在本地。表很多时，建议先在小库或测试库确认布局，再用于设计评审。

## 7. 导出数据与执行 SQL 文件

### 7.1 导出表数据

“导出数据”用于把整张表按字段、范围和格式写成文件。它与行右键的快速导出不同：快速导出只处理当前行或选中行（见 5.4），整表导出支持分页、条件、进度和取消。

打开入口：

- 数据页工具栏“导出”。
- 表右键菜单“导出” → “导出数据”。
- 行或选区右键菜单中的“导出”（快速导出当前行或选中行）。

数据页数据尚未加载时，工具栏“导出”会提示“请先加载表数据”；从表右键打开时会先加载字段，完成后再打开导出窗口。

#### 7.1.1 窗口结构

导出窗口分为“常规”“条件”“消息日志”三个页签：

| 页签 | 内容 |
| --- | --- |
| 常规 | 对象选择、格式选择、字段选择 |
| 条件 | 导出范围、自定义条件、预计行数与 SQL 预览 |
| 消息日志 | 导出进度、每批结果、错误与耗时 |

窗口底部按钮：

| 按钮 | 说明 |
| --- | --- |
| 关闭 | 关闭窗口；已开始的导出任务不会被关闭动作中断 |
| 导出 | 至少选中一个字段后可用；点击后先选择保存位置 |

#### 7.1.2 选择对象和格式

1. 在“对象”行确认“库”和“表”。库固定为当前数据库，不可切换；表可在同一数据库内切换，列表包含表和视图。
2. 在“格式”行选择输出格式：

| 格式 | 扩展名 | 文件内容 |
| --- | --- | --- |
| SQL | `.sql` | 每行一条 INSERT 语句，字面量与标识符按当前连接方言生成 |
| TXT | `.txt` | 制表符分隔，首行为字段名 |
| CSV | `.csv` | 逗号分隔，首行为字段名，文件带 UTF-8 BOM |
| JSON | `.json` | 对象数组，每行一条记录，缩进格式化 |
| XML | `.xml` | `<rows>` 根节点，每条记录一个 `<row>`，字段为 `<field name="...">` |

默认格式为 CSV。

#### 7.1.3 选择字段

“字段”区域显示字段名、类型、主键（PK）、非空（NOT NULL）和注释，右侧显示“已选/总数”。

- 点击字段行切换勾选。
- “全选”“反选”用于批量勾选；“仅当前可见字段”按数据页当前可见列选择，忽略已隐藏列。
- 一个字段都不选时，“导出”按钮不可用。

#### 7.1.4 选择导出范围

切到“条件”页签，在“导出范围”中选择：

| 范围 | 行为 |
| --- | --- |
| 当前筛选条件 | 沿用数据页当前的筛选和排序 |
| 导出全部 | 忽略筛选和排序，导出整表 |
| 自定义条件 | 使用导出窗口内单独设置的筛选和排序，不影响数据页 |

选择“自定义条件”后：

1. 点击“设置条件”（已有条件时显示“编辑条件”）。
2. 在条件窗口设置筛选和排序，点击“应用”。
3. 摘要行会显示“筛选 N 个 · 排序 M 个”；未设置时提示“未设置筛选和排序，将按全表导出”。
4. 需要重来时可点“清空”。

“预计导出”显示当前条件下的行数，旁边“刷新”可重新统计。下方“SQL 预览”显示实际取数 SQL，用于确认条件和排序是否符合预期。

#### 7.1.5 选择保存位置并开始

1. 点击“导出”。
2. 系统保存对话框默认打开下载目录，文件名默认为“表名-时间戳.扩展名”。
3. 选择位置并确认后，窗口切到“消息日志”，导出在后台执行。

执行细节：

- 每批读取 1000 行，日志按批次追加。
- 导出先写入同目录的 `.partial` 临时文件，全部成功后原子改名为目标文件；失败或取消会删除临时文件，不会留下半成品。
- PostgreSQL 导出在单个一致性快照事务内完成，其余类型按批分页读取。
- 任一字段的值在读取阶段被截断时，导出会直接报错并指出字段名，避免写出不完整数据。

#### 7.1.6 查看日志、取消和清理

消息日志顶部显示表名、格式、字段数、已导出行数、批次数、状态、耗时和文件路径，下方逐条列出批次结果。

| 按钮 | 说明 |
| --- | --- |
| 复制日志 | 把完整日志复制到剪贴板 |
| 取消导出 | 请求取消；当前批次结束后停止，按钮变为“停止中” |
| 清除任务 | 任务结束后可用；运行中的任务不能清除 |
| 关闭 | 关闭窗口，后台任务继续运行 |

任务运行期间，状态栏会显示导出进度；从状态栏重新打开可回到该任务的日志。取消或失败时，状态栏和消息日志会给出对应结果。

![数据导出](screenshots/manual/mysql-export.png)

> **注意**：导出文件可能包含敏感数据。完成后请检查文件权限，不要把真实业务数据提交到代码仓库。

### 7.2 执行 SQL 文件

“执行 SQL 文件”把本地脚本交给当前连接执行，适合初始化表结构、批量导入或迁移脚本。

打开入口：

1. 右键连接，选择“执行 SQL 文件”。
2. 右键数据库，选择“执行 SQL 文件”，会自动带上该数据库。

#### 7.2.1 填写执行信息

窗口分为“常规”“消息日志”两个页签。常规页签包含：

| 字段 | 说明 |
| --- | --- |
| 文件 | SQL 文件路径；点击“浏览”选择，或直接输入路径 |
| 连接 | 目标连接，默认取当前连接 |
| 数据库 | 目标数据库；连接未指定库时可留空，使用连接的默认数据库 |
| 编码 | UTF-8（默认）、UTF-8 BOM、GBK、GB18030、UTF-16 LE、UTF-16 BE |

“选项”：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 遇到错误时继续 | 开启 | 关闭后遇到第一条错误即停止 |
| 按分号拆分多个查询 | 开启 | 关闭后整个文件作为一条语句提交 |

没有选择文件时“执行”按钮不可用。文件为空会提示“SQL 文件为空”。

#### 7.2.2 执行与观察

1. 点击“执行”。
2. 窗口切到“消息日志”，实时显示连接、数据库、查询总数、已处理数、错误数、状态、耗时、文件名和路径。
3. 运行中可点击“取消执行”，当前 SQL 完成后停止，按钮显示“停止中”。
4. 结束后可“复制日志”或“清除任务”。

状态栏会显示执行进度；关闭窗口不会中断任务，可从状态栏重新打开日志。

PostgreSQL 连接下，脚本包含 psql 元命令或 `COPY ... FROM STDIN` 时，会改用本机 `psql` 执行，以保持与命令行脚本一致的行为。此时 `psql` 必须在系统 PATH 中可用，或在“设置” → “数据” → “PostgreSQL 客户端”中能检测到（见 8.1）。

> **注意**：脚本可能包含 `DROP`、`TRUNCATE`、`UPDATE` 等不可逆操作。执行前先在测试库验证，并确认目标连接和数据库没有选错。

> **提示**：大型脚本执行中不要直接强制退出应用。发生错误时，先确认已执行范围和数据库事务状态，再决定重试或补执行；关闭“遇到错误时继续”可以让失败位置更明确。

## 8. 数据库备份

### 8.1 首次配置

备份目录默认是应用可执行文件所在目录下的 `backup`，文件按 `{备份目录}/{库名}/` 分目录存放。每次新建备份时，弹框会用该目录预填“备份目录”，也可以当场改成其他目录，只影响本次任务。

原生客户端按数据库类型准备（SSH 隧道会转成本地端口后交给客户端；代理连接不被支持，会直接提示改用直连或 SSH 隧道，不会静默直连）：

- SQLite：无需外部工具，使用 SQLite 自带的 `VACUUM INTO` 生成快照。
- MySQL / MariaDB / TiDB：`mysqldump` 或 `mariadb-dump`，优先使用 PATH 中的工具。
- PostgreSQL：`pg_dump`，版本不能低于服务端版本；`psql` 用于含元命令或 `COPY ... FROM STDIN` 的脚本。

可以打开“设置” → “数据”，在对应客户端分组点击“检测”或“下载并安装”。该分区的保存按钮不可用，分组内手工填写的路径只对当前会话有效；要长期生效，请把客户端加入系统 PATH，或使用应用内下载安装。

只有配置中的备份目录被置空时才需要处理：备份标签页会提示“请先在设置中配置备份目录”，新建备份弹框也会给出提示；正常情况下默认目录已填好，不会出现该提示。

> **提示**：缺少 PostgreSQL 或 MySQL 客户端工具时，备份窗口顶部会显示警告横幅，并提供“前往设置”入口，不必等到点了“开始备份”才看到错误。

### 8.2 新建备份

打开入口：

- 右键数据库，选择“备份”。
- 右键表，选择“备份”；对象选择默认只勾选该表。
- 表右键“导出” → “导出数据库”，效果等同整库备份。
- 备份标签页工具栏“新建备份”。
- 侧边栏“备份”节点右键 → “新建备份”。

备份窗口分为“常规”“对象选择”“高级”“消息日志”四个页签。

#### 8.2.1 常规

| 项目 | 说明 |
| --- | --- |
| 备份数据库 | 当前库，只读 |
| 备份目录 | 默认填入设置中的 `backup_dir`（初始为可执行文件目录下的 `backup`），可点“选择”为本次备份换目录 |
| 备份方式 | 固定为“自动选择”，只读 |
| 备份文件名（模板） | 可留空；支持 `{timestamp}`（时间戳）和 `{database}`（库名）占位符 |
| 输出文件 | 实时显示解析后的完整文件名 |
| 备注 | 可空，成功后随备份记录保存，可在备份标签页继续编辑 |

“自动选择”按数据库类型和本机工具决定实际方式：

| 数据库 | 实际方式 |
| --- | --- |
| MySQL / MariaDB / TiDB | 找到 `mysqldump` / `mariadb-dump` 时用原生工具，否则用逻辑 SQL 备份 |
| PostgreSQL | 始终使用 `pg_dump` |
| SQLite | 生成完整数据库快照（`.db` 文件） |
| Oracle / SQL Server / 达梦 | 逻辑 SQL 备份 |

默认文件名格式为 `{库名}_{时间戳}.sql`；SQLite 输出 `.db`。目标文件已存在时拒绝覆盖。

#### 8.2.2 对象选择

“整库备份（全部对象）”默认勾选；此时备份执行时会重新枚举数据库，包含打开窗口后新增的表，并显示对象总数。

取消“整库备份”后按对象清单备份：

1. 在搜索框过滤表名。
2. 勾选表；可用“全选表”或“清空”批量处理当前筛选结果。
3. 库中存在视图时，可勾选“包含视图（N）”。

从表右键打开备份时，会自动取消整库模式并只勾选该表。

#### 8.2.3 高级

| 选项 | 默认 | 适用范围 |
| --- | --- | --- |
| 锁定所有表 | 关闭 | MySQL / MariaDB / TiDB 原生 mysqldump |
| 使用单一事务（仅 InnoDB） | 开启 | MySQL / MariaDB / TiDB 原生 mysqldump |
| 包含存储过程/函数（--routines） | 开启 | MySQL / MariaDB / TiDB 原生 mysqldump |
| 包含表结构 | 开启 | 原生 mysqldump、pg_dump、逻辑备份 |
| 包含表数据 | 开启 | 原生 mysqldump、pg_dump、逻辑备份 |
| 包含属主 OWNER（PG 原生） | 关闭 | PostgreSQL 原生 pg_dump |
| 包含 ACL 权限（PG 原生） | 关闭 | PostgreSQL 原生 pg_dump |

“锁定所有表”和“使用单一事务”互斥，打开一个会自动关闭另一个。表结构和表数据至少要保留一项；SQLite 快照必须同时包含两者。

> **提示**：mysqldump 9.x 客户端连接较老 MySQL 服务端时，例程查询可能不兼容。遇到 `Couldn't execute 'SELECT LIBRARY_NAME …'`，可取消“包含存储过程/函数”，或在设置中换用与服务端版本匹配的客户端。

#### 8.2.4 开始与观察

1. 点击“开始备份”。
2. 窗口切换到任务日志，显示文件名、数据库、方式、阶段、耗时和逐条日志。
3. 运行中可“取消任务”；任务结束前不能“清除任务”。
4. 结束后可“再次备份”回到新建表单，或“清除任务”关闭该条记录。

日志会列出跳过的对象和原因，例如客户端版本不兼容时跳过例程、TiDB 跳过存储过程。备份完成后写入两类记录：

- 磁盘上的备份文件；
- 应用数据库中的备份记录，包含表清单、视图开关、大小、时间和备注。

删除备份文件不会影响数据库；备份成功也不代表可恢复，重要数据仍需做恢复演练。

![数据库备份](screenshots/manual/mysql-backup.png)

### 8.3 管理备份

单击侧边栏数据库下的“备份”节点，打开该库的备份标签页。

工具栏：

| 按钮 | 说明 |
| --- | --- |
| 新建备份 | 打开备份窗口 |
| 从文件恢复 | 打开恢复窗口，手动选择备份文件 |
| 刷新 | 重新读取备份记录 |

列表列：名称、备份时间、备份表、文件大小、路径、备注、操作。

- “查看”打开备份表清单：显示“整库”、表数量或“无记录”（老备份没有表清单）。
- “恢复”用该备份文件打开恢复窗口。
- “记录”查看该备份的恢复历史，新→旧排列。
- “编辑”修改备注；留空表示清除备注。
- “删除”要求确认，删除后同时移除备份文件与备份记录，不可恢复。

运行中的备份任务会置顶显示阶段、日志和取消入口。

### 8.4 恢复数据库

恢复入口：

- 备份标签页工具栏“从文件恢复”。
- 备份列表某行的“恢复”。

支持的连接类型：MySQL / MariaDB / TiDB、PostgreSQL、SQLite、达梦、Oracle。SQL Server 等暂不支持，会提示“此数据库尚不支持恢复”。

#### 8.4.1 常规页

| 字段 | 说明 |
| --- | --- |
| 目标连接 | 只列出与备份同类型的连接 |
| 备份文件 | 可手动输入或点“选择”；macOS 下文件选择框默认定位到备份目录 |
| 目标名称 | 按恢复方式变化：新数据库名、目标新文件，或“现有库”下拉 |
| 恢复方式 | SQLite 固定“新文件”；达梦/Oracle 固定“新建 schema”；其余可选“新数据库”或“现有库” |

备份文件按内容识别格式，不依赖扩展名。SQL 转储恢复到数据库，SQLite 二进制备份恢复为新的 `.db` 文件。

#### 8.4.2 对象选择页

恢复方式为“新数据库”时，整库恢复备份中的全部对象，不需要逐表设置。

恢复方式为“现有库”时：

1. 选择备份文件和目标库后，应用自动探测备份内容与目标状态。
2. 表格列出每个对象：备份内容（结构＋数据、仅结构、仅数据、空对象）、目标状态（已存在/不存在）、还原动作。
3. 目标不存在且备份含结构时，默认“新建表”；目标已存在且有可用内容时默认“待选择策略”，必须逐行选择后才能继续；目标已存在但备份既无结构也无数据的对象只能“不处理”。

可选还原动作：

| 动作 | 说明 |
| --- | --- |
| 新建表 | 目标不存在时创建表并导入数据 |
| 重建表 | 删除目标表后按备份重建（破坏性） |
| 清空后导入 | 保留表结构，清空数据后导入（破坏性） |
| 追加数据 | 保留现有数据，追加备份数据 |
| 不处理 | 跳过该对象 |

存在“待选择策略”的对象时，“预检查”和“确认恢复”都不可用。

#### 8.4.3 高级页

| 选项 | 说明 |
| --- | --- |
| 事务范围 | “引擎默认”或“单事务（整任务）”；MySQL 在不含 DDL 的逐表恢复中才能兑现整任务单事务，否则回退并在计划中说明 |
| 完成验证 | “基础（对象存在）”或“逐表行数”；后者额外逐表统计行数，速度更慢 |

SQLite 快照恢复不显示这两项。

生成计划后表单会锁定。要改文件、目标或选项，先点底栏“修改目标”清除计划，再修改并重新“预检查”。

#### 8.4.4 预检查与执行

1. 点击“预检查”。应用解析备份、检查目标，生成恢复计划。
2. 在高级页底部查看计划摘要、逐对象动作、风险与警告。
3. 确认无误后点击“确认恢复”。
4. 计划包含“重建表”“清空后导入”或整库覆盖现有库时，会弹出破坏性操作确认，要求原样输入目标名称后才能执行。
5. 执行期间可在消息日志查看进度；运行中关闭窗口不会取消后台任务，可用“取消任务”请求停止。

> **注意**：恢复会写入目标库，重建和清空动作会删除现有数据且无法撤销。执行前确认目标连接、目标库和逐表动作，生产库优先先在测试库演练。

> **提示**：备份文件和备份记录是两套东西。手动移动或删除备份文件后，列表中的旧记录可能失效；恢复前先在文件选择框中确认文件仍然存在。

## 9. 用户与权限管理

FluxDB 把账号、成员关系和授权收在同一个页签里，打开连接即可维护，不用另开查询窗口拼 DDL。

### 9.1 支持的数据库与入口

| 数据库 | 页面标题 | 管理对象 |
| --- | --- | --- |
| MySQL / MariaDB / TiDB | 用户与权限 | 用户、角色与库级权限 |
| PostgreSQL | 用户与角色 | 集群级角色、成员关系与对象权限 |
| KingbaseES | 用户与角色 | 沿用 PostgreSQL 页面与 `pg_catalog` 查询，尚未在 Kingbase 上单独回归 |
| SQL Server | 用户与角色 | 登录名、数据库用户、服务器/数据库角色与显式权限 |
| Oracle / 达梦 DM8 | 用户与权限 | 账号（即 Schema）、角色、系统权限与对象权限 |

SQLite、MongoDB、Redis 不显示该入口：它们没有同类的账号授权模型。

入口：

1. 在左侧连接树右键连接，选择“用户与权限”。
2. 页面打开后先点“刷新”加载列表。当前账号缺少读取权限时，列表会给出空状态提示，而不是把错误当成“没有用户”。

![用户与权限](screenshots/manual/mysql-user-admin.png)

### 9.2 公共页面与保存流程

四个面板的外观一致：顶部工具栏放连接名、数据库类型和“保存 / 取消 / 刷新 / 删除”；左侧是账号或角色列表，支持搜索和“新增用户”；右侧是分页签的编辑区。

所有修改都先留在本地草稿里，不会边输入边执行：

1. 在列表中选择现有账号，或点“+”新建。
2. 在“常规 / 高级 / 成员关系 / 权限”中修改。新建账号时这些内容可以一次填完。
3. 打开“SQL 预览”核对语句。该页只读，不负责执行。
4. 点顶部“保存”，弹出“确认执行的 SQL”。
5. 核对后点“执行”。成功提示出现后，再点“刷新”确认列表与授权已落库。

> **注意**：确认框提示“以下语句将按顺序逐条执行，任一失败后续语句不再执行，已执行的不会回滚”。MySQL、Oracle、达梦会在失败时报告“已执行 N/M 条”；PostgreSQL 与 SQL Server 在单事务内整批回滚。遇到失败先刷新，按实际生效情况重跑剩余部分，不要直接重复整批。

“取消”只丢弃本地草稿，不影响数据库。存在未保存修改时切换账号或页签，部分面板会先要求保存或放弃。

**口令显示策略因数据库而异**，预览前先确认屏幕环境：

- MySQL / MariaDB / TiDB、PostgreSQL：SQL 预览与确认框按草稿显示明文口令。
- SQL Server：页面展示时会还原明文；内部保存的预览和审计回执使用掩码。
- Oracle / 达梦：预览与执行回执都显示 `********`，不回显明文。

口令只进入内存草稿和本次执行语句，不写入 SQL 历史、应用日志或 AI 上下文。共享屏幕、录屏或截图前请先关闭预览。

### 9.3 MySQL / MariaDB / TiDB

三者共用 MySQL 面板。MariaDB 的账号 DDL 单独适配：新建用户默认 `mysql_native_password`，按 `IDENTIFIED VIA <plugin> USING PASSWORD(...)` 生成；MySQL 默认 `caching_sha2_password`，按 `IDENTIFIED WITH <plugin> BY '...'` 生成。角色是无 Host 的账号，授权、撤销和默认角色只写角色名。面板按连接类型自动切换，不需要手改 SQL。

#### 9.3.1 常规

| 字段 | 说明 |
| --- | --- |
| 用户名、主机 | 新建时必填。Host 决定账号匹配来源，例如 `%`、`localhost`、`10.0.%` |
| 插件 | 认证插件下拉。MySQL 候选含 `caching_sha2_password`、`mysql_native_password`、`sha256_password`、`auth_socket`、`mysql_clear_password`；MariaDB 候选为 `mysql_native_password`、`ed25519`、`unix_socket`、`pam` |
| 密码、确认密码 | 两次输入必须一致；留空表示不修改现有口令 |
| 密码过期策略 | 选择服务端支持的过期策略；修改现有账号时按下拉值生成 `ALTER USER` |

#### 9.3.2 高级

资源限制留空表示不限制，填写后分别对应 `MAX_QUERIES_PER_HOUR`、`MAX_UPDATES_PER_HOUR`、`MAX_CONNECTIONS_PER_HOUR`、`MAX_USER_CONNECTIONS`。

“SSL 类型”选择 `SPECIFIED` 后才会出现 `SSL Cipher`、证书发行者和证书主旨；其他类型按“不要求 / 任意”生成语句。

#### 9.3.3 成员关系

左右两张表分别是“成员属于”和“成员”：

- “成员属于”列出当前用户已加入的角色，勾选或取消表示授予/收回该角色。
- “成员”列出已授予当前用户的成员，用于把当前账号当作角色使用。
- 没有可授予对象时显示空提示，不会给空白下拉。

#### 9.3.4 权限

权限表按数据库分行。每行勾选权限项并决定是否带 `GRANT OPTION`。“添加权限”新增一行数据库授权；空表提示“暂无权限配置，点击添加权限开始”。

保存时只比较草稿与原始行：

- 新增勾选项生成 `GRANT`。
- 取消勾选项生成 `REVOKE`，确认框会标为危险操作。
- 勾选 `GRANT OPTION` 但权限没变时，单独补发带授权的 `GRANT`。
- 改数据库名视为撤销旧库授权、再授予新库。

### 9.4 PostgreSQL

PostgreSQL 页面标题是“用户与角色”，管理的是集群级角色，不区分“用户”和“组”——能登录的角色就是通常说的用户。

#### 9.4.1 列表与常规

列表支持“全部 / 可登录 / 不可登录 / 预定义”筛选。预定义角色（`pg_*`）只读，属性由系统管理。

| 字段 | 说明 |
| --- | --- |
| 角色名 | 新建必填。重命名会让旧的 MD5 口令失效 |
| 允许登录 | 对应 `LOGIN` / `NOLOGIN`。`NOLOGIN` 不会终止已有会话，也不清除已有口令 |
| 密码操作 | “保持不变 / 设置新密码 / 清除密码 / 不设置密码” |
| 新密码、确认密码 | 仅在“设置新密码”时出现，两次必须一致 |
| 密码有效期 | 可保持不变、清除或自定义截止时间；清除会显式写 `infinity` |
| 连接数限制 | `-1` 表示不限制；这是普通连接限制，不是精确限流 |

#### 9.4.2 高级

“角色能力”包含 `CREATEDB`、`CREATEROLE`、`INHERIT`、`REPLICATION`；“敏感能力”包含 `SUPERUSER`、`BYPASSRLS`，授予前者会绕过权限检查，授予后者会忽略行级安全策略。

`INHERIT` 的含义随版本变化：PG15 及以前控制是否自动继承所属角色权限；PG16 起是“新成员授权的默认值”，不是已有成员关系的总开关，页面会按服务端版本给出提示。

#### 9.4.3 成员关系

“所属角色”编辑 `GRANT 组角色 TO 当前角色`；“此角色的成员”编辑 `GRANT 当前角色 TO 成员`。新授权默认开启 `INHERIT/SET`，保存前可在 SQL 预览核对。PG15 及以前没有成员级 `INHERIT/SET` 选项。

#### 9.4.4 权限

先选择数据库、对象类型和对象，页面自动读取权限。表格列包括数据库、对象、权限、直接授予、可再授权、当前有效和来源。

- “当前有效”包含直接授权、成员继承、`PUBLIC`、属主和超级用户来源；撤销直接授权后，权限仍可能因其他来源保持有效。
- 目标属主的 ACL 为 `NULL` 时表示“默认权限”，不等同于空授权；页面会显示属主并说明这一点。
- 函数 `EXECUTE` 默认授予 `PUBLIC`，看到有效权限时不要误判为显式授权。
- 变更进入“待保存的授权变更”，点顶部“保存”统一提交。

> **提示**：PostgreSQL 的授权审计回执会掩码口令；SQL 预览与确认框仍按草稿显示明文。

### 9.5 SQL Server

SQL Server 分服务器层和数据库层管理。打开页面后，先在标题栏的“目标数据库”下拉中选择要管理的库。

- 连接配置了默认数据库时可自动选中；没有配置时只加载可访问库列表，未选库前“+”保持禁用。
- 切换数据库会重新加载该库的用户、角色和权限，不会修改连接的默认数据库。
- 只有实际改过字段才算未保存变更；打开空白新建表单不会锁住数据库。存在未保存变更时，必须先保存或取消才能切换。
- 通信中断等结果不确定时，页面标记“需核实”，此时禁止直接重试，先点“刷新”确认。

左侧列表可按“全部 / 登录名 / 用户 / 角色”筛选。右侧页签为“常规 / 成员关系 / 权限 / SQL 预览”。

| 对象 | 能做什么 |
| --- | --- |
| 登录名 | 创建/启停 SQL 认证登录名、改密、修改默认数据库、删除；Windows 登录名只读 |
| 数据库用户 | 创建映射到已有登录名的用户，修改登录映射和默认 Schema |
| 角色 | 查看服务器角色和当前数据库角色，管理固定/自定义数据库角色的成员；固定角色不能删除 |
| 权限 | 读取并编辑显式服务器、数据库、Schema 和对象权限，支持 `GRANT`、`WITH GRANT OPTION`、`DENY`、`REVOKE` |

权限页在保留现有权限的同时展开添加面板。选择权限后点“添加到待保存列表”，新行立即出现并标记“待保存”；添加面板保持展开，可继续添加。待保存行可单独移除，全部提交仍用顶部“保存”。

保存时在单事务中按服务器/数据库上下文依次执行，成功后自动刷新。撤销带 `WITH GRANT OPTION` 的权限时，SQL Server 要求 `CASCADE`；预览会明确显示，普通 `GRANT` / `DENY` 不自动级联。

创建可登录业务账号通常分两步：先在“登录名”新建 SQL Server 登录名，再在“用户”新建映射到该登录名的数据库用户，最后在“成员关系”和“权限”授予访问范围。这些变更可同时加入同一待保存计划，一次事务提交，不要求逐步落库。

当前不包含 Windows 集成认证、Azure AD、包含数据库用户、列级权限编辑和用户自定义服务器角色。目录里没有显式权限行，也不代表角色没有继承或固定角色隐含权限。

### 9.6 Oracle 与达梦 DM8

Oracle 与达梦按账号（即 Schema）管理，模型与其他数据库不同。

- 左侧列表来自 `ALL_USERS`，会列出当前账号能看到的全部账号名。
- 只有“当前登录账号”自己的角色、系统权限、对象权限和配额可读。选中其他账号时整页显示为不可读，不画成空授权，也不提供撤销入口——把读不到的授权显示成可直接撤销，会诱导出错误的 `REVOKE`。
- 右侧分五页：**常规 / 角色 / 系统权限 / 对象权限 / SQL 预览**。三份授权清单各自有编辑器，不需要先选类型；授权名可手填，也可从当前账号可转授的候选中选。候选为空时下拉不出现，仍可手填。
- 点“加入待执行”可继续添加多条，保存时并入同一份计划，列表条目可单独移除。
- 新建账号默认不能登录，需要同时授予 `CONNECT` 角色。Oracle 的表空间和 profile 留空表示使用模板默认值。
- 口令在预览和执行回执中都显示为 `********`，明文只存在内存草稿。
- Oracle 的用户/权限 DDL 会隐式提交，失败后无法整批回滚。失败提示会说明已执行到第几条；此时应刷新，并按实际生效情况重跑剩余语句。
- CDB/PDB 场景下公共账号（`C##` 前缀）与本地账号作用域不同，当前不做自动跨容器切换。

达梦 DM8 复用同一面板，差异只在方言：

- 登录权限是系统权限 `CREATE SESSION`，达梦没有 `CONNECT` 角色。
- `CREATE USER` 不接受 `PROFILE`，建号后通过 `ALTER USER ... PROFILE` 设置。
- 没有 `QUOTA ... ON ...` 子句。
- 其余“一次保存”、隐式提交和只读当前账号的行为与 Oracle 一致。

### 9.7 安全与回滚注意

- 删除账号、撤销授权、修改角色成员关系都可能立即中断业务，操作前先确认依赖该账号的应用、定时任务和连接池。
- 需要保留现有权限时，先刷新再改；不要基于过期页面做批量撤销。
- Oracle / 达梦为隐式提交，MySQL 多语句也可能部分成功；失败后先刷新核实，再决定补执行还是回滚。
- 生产环境优先用最小权限账号管理用户；不要用业务账号做授权变更。
- 不要截图或录屏包含明文的 SQL 预览。需要分享语句时，先删除或替换口令。

## 10. 使用 Redis

Redis 连接按逻辑数据库组织。展开连接会看到 DB 0、DB 1……每个逻辑库是一个独立标签页，键浏览、命令执行和发布订阅都绑定当前 DB。

Redis Cluster 只支持 DB 0；单机或主从部署按服务端配置提供多个逻辑库。

### 10.1 打开 Redis 数据库

1. 创建并连接 Redis。
2. 在左侧连接树展开连接，选择逻辑数据库，或右键选择“打开数据库”。
3. 标签页打开后进入键浏览页面。

![Redis 键浏览与详情](screenshots/manual/redis-db.png)

页面分为三块：顶部搜索栏、左侧键列表、右侧详情区。键列表和详情都只加载当前逻辑库，切换 DB 需要打开另一个标签页。

### 10.2 浏览、搜索与刷新

搜索栏从左到右：

| 控件 | 说明 |
| --- | --- |
| 类型 | “所有”或 string / list / set / zset / hash / stream / json，只显示该类型键 |
| 搜索框 | 按 Redis `SCAN MATCH` 通配符匹配键名：`*` 匹配任意多个字符，`?` 匹配一个字符；其余字符按字面匹配。输入后按 Enter 或点放大镜应用，匹配不区分大小写 |
| 清空 | 搜索框有内容时出现，清空查询并恢复完整列表 |
| 搜索历史 | 打开当前“连接 + 逻辑库”的最近搜索记录，点击即复用；上限 200 条，按连接和 DB 隔离 |
| 刷新 | 重新扫描当前库。键列表状态栏显示上次刷新距今时间；加载中显示“正在刷新…” |
| 新增键 | 打开新增 Key 抽屉 |

键列表有两种展示：

- **平铺**：一行一个完整键名。默认模式。
- **Folder**：按冒号 `:` 分层折叠，例如 `demo:orders:list` 显示为 `demo` → `orders` → `list`。展开/收起只影响展示，不改变键本身。

列表底部状态栏显示“结果 N · 已扫描 M”。键量大时列表是渐进扫描结果，不会一次性执行 `KEYS *`；还有更多数据时点“继续扫描”加载下一批。

键列表列：

| 列 | 内容 |
| --- | --- |
| 键 | 键名。Folder 模式下叶子只显示最后一段 |
| 类型 | string、list、set、zset、hash、stream、json |
| 值 | 有界预览，长值会截断 |
| 大小 | 值的字节数，未完整加载时会标注 |

### 10.3 新增 Key

1. 点搜索栏右侧“新增键”，打开右侧抽屉。
2. 选择类型：String、Hash、List、Set、ZSet、Stream 或 JSON。
3. 填写 Key 名称。名称不能为空，也不能包含控制字符。
4. 填写 TTL（可选）。单位是秒，必须是大于 0 的整数；留空表示永不过期。
5. 按类型填写内容：

| 类型 | 需要填写 |
| --- | --- |
| String | 值 |
| Hash | 一个或多个字段/值 |
| List | 一个或多个元素，并选择插入方向“头（左端）”或“尾（右端）” |
| Set | 一个或多个成员 |
| ZSet | 成员与分值，分值必须是数字 |
| Stream | Entry ID 可留空自动生成，或填 `毫秒-序号`；至少一组字段/值 |
| JSON | 完整 JSON 文本；可用“格式化/校验”先美化并检查合法性 |

6. 保存。成功后停留在当前数据库标签页，列表刷新并自动选中新键；不会为新键另开标签页。

JSON 类型优先使用 RedisJSON：服务端加载了 RedisJSON 时执行 `JSON.SET`。没有加载时自动退回普通字符串保存 JSON 文本，键列表仍按内容识别为 json。

> **注意**：新建 Key 不会覆盖同名键。若目标已存在，保存会失败并保留抽屉内容，换名后再试。

### 10.4 查看和编辑 Key

选择键后，右侧详情区顶部是元信息栏，下面是按类型变化的编辑区。

#### 10.4.1 元信息、改名与 TTL

| 操作 | 说明 |
| --- | --- |
| 键名称 | 点击进入编辑，保存时使用 `RENAMENX`。目标键已存在会报错，不会覆盖 |
| TTL | 填秒数后保存，执行 `EXPIRE`；留空保存表示移除过期时间，执行 `PERSIST`。TTL 必须大于 0 秒 |
| 刷新 | 重新读取当前键的值、类型和 TTL |
| 保存 / 放弃 | 提交或丢弃当前详情区的修改 |

修改值本身不会顺带清掉原 TTL：写值前记录现有 TTL，写入后补回；如果本次同时显式改了 TTL，以显式值为准。

![Redis 键详情中的 JSON 值](screenshots/manual/redis-db.png)

#### 10.4.2 String 与 JSON

- String 显示完整文本；大值先显示部分内容，点“加载全部”后再编辑或复制。
- 支持复制和下载。二进制值不能复制，只能下载。
- “格式转换”可对文本做格式化处理，保存前先在编辑区确认结果。
- JSON 使用带语法高亮的编辑器；“格式化/校验”不合法时会直接报错，不会保存半截内容。

#### 10.4.3 Hash

- 表格按字段分页显示，底部显示“显示 x / 共 y 个字段”。
- “新增字段”添加字段/值；字段名不能为空。
- 值超过 1 MB 会截断，需点“查看完整值”进入独立编辑。
- Hash 字段级 TTL 需要 Redis 7.4 及以上；低版本不显示该能力。值被截断时字段级 TTL 编辑会禁用，避免误写原始数据。

#### 10.4.4 List

- 按位置显示元素，底部显示“显示 x / 共 y 个条目”。
- “新增条目”可选择“头部添加”或“尾部添加”。
- 删除按数量执行：选择从头部或尾部移除 N 个，N 必须是大于 0 的整数；删除前有二次确认，删除后不可撤销。

#### 10.4.5 Set

- 显示成员总数，支持按成员名筛选。
- “新增 Member”可一次添加一个或多个成员，成员不能为空。
- 删除成员有确认提示，删除不可撤销。

#### 10.4.6 ZSet

- 表格显示成员和分值，成员只读，分值可编辑。
- 鼠标移到分值上出现编辑图标，改完确认；分值必须是数字。
- 删除成员需二次确认。

#### 10.4.7 Stream

- 可按起始/结束时间筛选条目，时间格式为 `YYYY-MM-DD HH:MM:SS`；起始不能晚于结束。
- 底部显示“显示 x / 共 y 个条目”。
- “新增 Entry”支持指定 Entry ID 或留空自动生成；可填 MAXLEN 做近似裁剪，留空表示不裁剪。
- 至少需要一组 Field/Value；字段名不能为空。
- 消费者组区域可展开查看组名、消费者数、未确认数和最后投递 ID；没有消费者组时显示空提示。
- 删除 Entry 需确认。

#### 10.4.8 删除 Key

键列表提供删除入口。确认框会提示“将被删除，此操作不可撤销”。删除前确认当前连接与 DB 编号，避免误删同名键。

### 10.5 Redis Workbench

右键 Redis 逻辑数据库，选择“Redis Workbench”。它不会打开 SQL 编辑器。

![Redis Workbench](screenshots/manual/redis-workbench.png)

页面结构：顶部工具栏、命令输入区、结果区。输入区和结果区可上下分栏，也可切换为左右分栏；拖动中间手柄调整大小，尺寸会记住。

1. 在输入区输入一条或多条 Redis 命令。
2. 输入时光标下方显示当前命令的参数签名；必填参数填完后提示自动消失，也可按 Esc 关闭。
3. 点“运行”。空文本或正在运行时按钮禁用。
4. 一次运行中的每条命令各生成一张结果卡片，按执行顺序追加；单条失败不会阻止后续命令。
5. 卡片头部显示命令、成功/失败、执行时刻和耗时（毫秒）；点头部折叠或展开。
6. JSON 命令结果可在 Text / JSON 视图间切换。
7. 卡片右侧可单独重跑或删除该条记录；“清空结果”删除全部卡片，但不影响数据库。
8. 顶部“历史”打开命令历史抽屉，按连接和逻辑库展示；可搜索，单条可删除，也可清空。点“重跑”会把该命令填回 Workbench 并执行。

注意事项：

- `SUBSCRIBE`、`PSUBSCRIBE`、`MONITOR` 会阻塞连接，Workbench 不支持；需要时用 Redis CLI。
- 只读连接下，输入中只要包含写命令，整批不会发送到服务端，直接返回只读错误。
- `FLUSHDB`、`FLUSHALL`、`SHUTDOWN`、`DEBUG`、`SLAVEOF`、`REPLICAOF`、`CLUSTER`、`MIGRATE`、`CLIENT` 作为首个命令词时触发二次确认；确认框会展示待执行的命令。该行为可在设置中关闭。

### 10.6 Redis CLI

1. 右键 Redis 逻辑数据库。
2. 选择“Redis CLI”。
3. 在终端中输入命令并回车执行。

![Redis CLI](screenshots/manual/redis-cli.png)

CLI 是真实的 `redis-cli` PTY 会话，不是模拟终端：提示符、行编辑、历史和补全都由 `redis-cli` 提供。顶部信息条显示“连接名 · DB 编号 · redis-cli”。

- 需要本机安装 `redis-cli`。应用会先查当前 PATH，再补查常见安装目录；找不到时终端启动失败。
- 支持 ↑/↓ 翻命令历史、Tab 补全，以及终端内的复制和粘贴。
- 危险命令同样触发确认；取消只清掉当前命令行，不退出会话。
- 只读连接会连到本机只读代理：读命令正常执行，写命令直接返回 `READONLY 连接已设为只读，未执行`，不会到达服务端。代理启动失败时终端直接报错退出，不会无护栏直连。
- CLI 的权限等同于连接账号。先核对连接名和 DB 编号，再执行 `FLUSHDB`、`DEL`、`SCAN` 等命令。

### 10.7 Pub/Sub

1. 右键 Redis 逻辑数据库。
2. 选择“打开 Pub/Sub”。
3. 在顶部订阅框输入频道名，点“订阅”。
4. 在底部发布面板填写频道和消息，点“发布”。
5. 点击“已订阅通道”里的频道标签可取消订阅；标签右侧 `×` 表示点击即退订。

页面说明：

- 顶部显示连接、DB、连接状态（连接中 / 已连接 / 失败）和已订阅数量。连接或协议错误会显示红色错误条，不会静默失败。
- 订阅的是精确频道名，界面不提供 pattern 订阅；需要 `PSUBSCRIBE` 时用 Redis CLI。
- 消息表按“时间 / 频道 / 消息”三列显示，最新消息在第一页首行；每页 50 条，最多保留最近 500 条。
- 点击发布后保留频道名、清空消息内容，便于连续向同一频道发送。如果本页也订阅了同一频道，会正常收到这条消息。
- 只读连接不能发布，点击发布只提示只读，不会入队。
- 清空按钮只清空本地消息表，不影响 Redis；关闭标签页会断开订阅会话。

> **提示**：Pub/Sub 是实时广播，没有历史补发。页面关闭期间发布的消息不会在重新打开后出现；需要保留消息请使用 Stream。

## 11. 使用 MongoDB

MongoDB 按“库 → 集合 → 文档”组织。FluxDB 在集合级打开标签页，页面内分为“文档 / 聚合 / 索引 / 集合信息”四个分节；视图（View）以只读方式打开。

### 11.1 连接 MongoDB

1. 点击“添加连接”，选择 MongoDB。
2. 优先在顶部“连接串 / URI”粘贴 `mongodb://` 或 `mongodb+srv://` 地址，点击“导入”。FluxDB 会回填主机、SRV、账号、默认库与认证库，核对后再补密码。
3. 也可以直接填写下表字段。

| 字段 | 必填 | 说明 |
|---|---|---|
| 名称 | 是 | 连接在侧边栏显示的名称 |
| 主机 / 端口 | 是 | 默认端口 `27017`；多主机可参照连接串写法 |
| SRV（MongoDB Atlas） | 否 | 使用 `mongodb+srv://` 的 DNS 拓扑发现方式 |
| 用户名 / 密码 | 否 | 启用认证时填写；密码不写入明文配置 |
| 默认库 | 否 | 打开连接后默认定位的数据库 |
| 认证库 | 否 | 可选，通常为 `admin`；账号建在业务库时填业务库名 |
| 认证机制 | 否 | 默认由驱动协商，也可选 SCRAM-SHA-256、SCRAM-SHA-1、MONGODB-X509 |
| TLS | 否 | 在“传输层安全 (TLS)”中配置 CA、客户端证书、SNI 与证书校验 |

4. 点击“测试”，通过后保存并连接。

> **注意**：连接串可能包含密码。不要把含密码的连接串写入脚本、日志、工单或代码仓库。

### 11.2 打开集合与页面结构

1. 展开 MongoDB 连接，再展开目标数据库。
2. 展开“集合”分组，双击集合或视图打开标签页。

![MongoDB 集合浏览](screenshots/manual/mongo-collection.png)

页面顶部是分节页签，右侧在只读对象上显示“只读”标记：

| 分节 | 用途 |
|---|---|
| 文档 | 查询、分页、查看与增删改文档 |
| 聚合 | 用阶段卡片搭建聚合管道并逐步预览 |
| 索引 | 查看索引定义、大小、使用统计，删除普通索引 |
| 集合信息 | 查看集合类型、文档数、平均大小、数据/磁盘大小与索引数 |

“文档”页下方工具条可切换三种展示方式：

| 展示方式 | 说明 |
|---|---|
| 文档 | 一篇文档一张卡片，字段带 BSON 类型徽标，对象和数组可展开 |
| 表格 | 按字段并集生成列，适合横向对比多篇文档 |
| JSON | 整篇 Extended JSON，支持折叠层级 |

常用右键入口：

| 位置 | 菜单项 |
|---|---|
| 数据库 | 创建集合、命令行终端、命令工作台、刷新、删除数据库 |
| 集合 | 置顶、复制名称、刷新、导出；可写集合另有重命名、导入数据、删除集合 |
| 视图 | 只有置顶、复制名称、刷新、导出（视图不可写） |
| 连接 | 显示连接信息、刷新；“查看性能指标”当前为置灰占位 |

> **提示**：集合右键菜单中的“导入数据”与结果条上的“导入文档”打开同一个导入弹窗。

### 11.3 查询文档

“文档”页顶部的过滤框是查询主入口：

1. 在“过滤”中输入 Extended JSON 对象，例如 `{ city: "上海" }`。查询条件接受宽松写法，键名可不加引号；留空等同 `{}`。
2. 点击“查询”执行，或点击“重置”恢复默认查询并立即重查。输入过程中不会自动执行。
3. 点击“更多选项”展开附加条件。

| 条件 | 说明 |
|---|---|
| 投影 | 只返回指定字段，如 `{ "name": 1, "city": 1 }` |
| 排序 | 值为 `1`（升序）或 `-1`（降序），如 `{ "created_at": -1 }` |
| 返回条数 | 单页 1–500 条，默认取设置中的分页大小 |
| 条件构建 | 用字段 / 运算符 / 值生成过滤 JSON |
| 排序规则 | Collation 对象，如 `{ "locale": "zh" }` |
| 起始位置 | 跳过多少篇文档，用于分页或手动跳转 |
| 索引提示 | 索引名或键定义，如 `"_id_"` 或 `{ "age": 1 }` |
| 执行上限 | 服务端最长执行时间，单位毫秒；留空不限制 |

“条件构建”支持 AND / OR / NOR 逻辑组，以及针对数组字段的 `$elemMatch` / `$not + $elemMatch` 组。字段运算符包括 `$eq`、`$ne`、`$gt`、`$gte`、`$lt`、`$lte`、`$in`、`$exists`。构建器会把条件写回过滤框；如果过滤条件含有构建器无法无损表达的写法（例如 `$regex`、复杂嵌套对象），会提示继续手写 JSON，不会猜测改写。

执行后：

- 结果条左侧显示“共 N 条”或“返回 N 条”。不足一页时可直接得到总数；还有下一页时按本页返回数显示。
- “新增文档”“导入文档”只在可写集合上显示；视图和只读连接不显示。
- 底部分页显示当前范围和页码，点击上一页 / 下一页会把新的“起始位置”写回查询面板并重新查询。
- 单次查询最多返回 500 篇文档。需要更多数据时用分页或导出。

> **注意**：排序字段值只接受 `1` / `-1`；`$in` 的值必须是数组，`$exists` 的值必须是布尔值。条件写错会直接显示解析错误，不会带着半截条件执行。

### 11.4 查看与编辑文档

可写集合中，文档卡片右侧提供四个操作：

| 操作 | 行为 |
|---|---|
| 编辑文档 | 打开右侧编辑抽屉，整篇替换该文档 |
| 复制文档 | 以当前文档为模板新建一篇，自动去掉 `_id` |
| 复制到剪贴板 | 复制完整 Extended JSON |
| 删除文档 | 按 `_id` 定位，确认后删除 |

视图只保留“编辑文档”（实际打开只读详情）与“复制到剪贴板”。

编辑抽屉的规则：

- 正文是 Extended JSON，保留 ObjectId、Date、Decimal128 等 BSON 类型。
- 保存时整篇替换原文档，`_id` 是定位条件且不可修改。
- 保存成功后重新查询当前页并关闭抽屉；保存失败时草稿保留，可直接修改后重试。
- 点击“取消”或关闭抽屉视为明确丢弃；切换到另一篇文档时若有未保存修改，会先询问“继续编辑”还是“放弃并切换”。
- 详情区会提示“文档内容不进入 AI 上下文，需要时由 AI 按权限只读读取”。

新增与复制：

1. 点击结果条的“+”（新增文档），或文档卡片上的“复制文档”。
2. 新增时只预填一个客户端生成的 ObjectId；复制时正文已去掉 `_id`，由数据库生成新的 `_id`。
3. 修改字段后点击“插入”。插入成功会提示新文档的 `_id`。

> **注意**：删除文档不可恢复；删除确认框会显示目标 `_id`。视图、只读连接以及没有写入权限的账号不能修改或删除文档。

### 11.5 聚合

“聚合”分节用阶段卡片搭建管道：

1. 点击“添加阶段”，新卡片默认是 `$match`。
2. 在卡头下拉中选择运算符，可输入关键字筛选。支持过滤、投影、分组、排序、限制、展开、关联、分面、分桶、窗口函数等常用阶段。
3. 在左栏填写该阶段的 Extended JSON 参数；右栏点击预览按钮查看“当前阶段及之前所有阶段”的输出。
4. 卡头提供停用 / 启用、上移、下移、删除与折叠。停用的阶段会保留在界面上，但不进入执行的管道。

预览规则：

- 每个阶段最多取 10 篇文档，用于确认结构和取值，不是全量结果。
- 每张卡片独立预览，不会自动运行后面的阶段。
- `$out` / `$merge` 会写回集合，预览会被拒绝，并提示“写库阶段（$out / $merge）不能预览”。
- 参数不是合法 JSON 时，卡片边框和说明会标红；整条管道无法解析时，页面顶部显示错误。

> **注意**：聚合页只做阶段搭建与预览，不提供整条管道的“写库执行”按钮。需要写入结果时，请使用文档操作或命令工作台中的白名单写方法；命令工作台同样拒绝在 `aggregate` 中使用 `$out` / `$merge`。

### 11.6 索引

切到“索引”分节时按需加载，页签上会显示索引数量。

- 表格列为“名称与定义 / 类型 / 大小 / 使用 / 平均使用频率 / 属性 / 状态”，点击表头可排序。
- 类型包括常规、地理空间、哈希、文本、通配、列存储、聚簇；属性显示唯一、稀疏、部分、TTL、排序规则、隐藏、复合等标记。
- 展开索引可查看键定义和部分索引的过滤条件。
- 使用次数和频率来自 `$indexStats`，只反映当前连接节点；权限不足或数据不可用时显示“使用数据不可用”，不会用 0 冒充。
- 状态显示“就绪”或“构建中”。
- 点击行尾的删除按钮并确认后删除索引；`_id_` 是集合固有索引，不显示删除入口。

> **注意**：删除索引后，依赖它的查询会退回全表扫描；重建大集合的索引可能耗时并占用磁盘。

### 11.7 集合信息与集合管理

“集合信息”显示集合名、类型（集合 / 视图 / 时间序列集合）、所属数据库、文档数、平均文档大小、数据大小、磁盘占用和索引数。无法读取的统计显示“未知”；视图还会显示来源集合。

**创建集合**

1. 右键数据库，选择“创建集合”。
2. 填写集合名并确认。创建成功后侧边栏刷新。

**新建数据库**

MongoDB 的空库不会实际存在，因此“新建数据库”必须同时指定“首个集合”：

1. 右键连接，选择“新建数据库”。
2. 填写数据库名称和首个集合名。
3. 确认后 FluxDB 通过创建首个集合来隐式创建数据库。

**重命名集合**

1. 右键集合，选择“重命名”。
2. 输入新名称并确认。已打开的集合标签页会同步改为新名称。

**删除集合**

1. 右键集合，选择“删除集合”。
2. 确认框会显示集合名和当前文档数（无法获取时显示“文档数未知”），并提示文档与索引无法恢复。
3. 确认后集合被删除，已打开的对应标签页会关闭。

**删除数据库**

右键数据库选择“删除数据库”，确认后删除该库及其中所有集合。此操作不可恢复。

**连接信息**

右键连接选择“显示连接信息”，可查看服务器版本、发行版、拓扑类型、副本集、主节点、成员、协议版本、运行时长，以及各数据库大小。点击“刷新”重新读取，“关闭”退出弹框。“查看性能指标”当前为置灰占位，尚未采集指标。

> **注意**：视图只读，不提供重命名、导入、删除集合，也不提供新增、复制文档和删除文档入口；卡片上的编辑按钮只打开只读详情。

### 11.8 导入与导出文档

#### 导入文档

入口有两个：集合右键“导入数据”，或结果条上的“导入文档”。

1. 选择目标集合与本地文件。
2. 选择后 FluxDB 按文件内容嗅探格式，不依赖扩展名：

   | 首个非空白字符 | 识别格式 |
   |---|---|
   | `[` | JSON 数组，如 `[{...}, {...}]` |
   | `{` | JSONL，每行一篇文档 |
   | 其他 | CSV，首行为字段名 |

3. CSV 可设置分隔符（逗号 / 分号 / 制表符 / 竖线）和“空值按 null”。字段类型可逐列改选，支持 ObjectId、String、Int32、Int64、Double、Boolean、Date、Null、Mixed。
4. 预览区最多展示前 50 条，导入时会处理完整文件。
5. 点击“开始导入”；运行中可点“停止”，已写入的批次保留。

导入行为：

- 按每批 1000 篇写入，批内单条失败不影响其他文档。
- 坏文档（例如 `_id` 冲突、类型解析失败）跳过并继续，结束后报告成功数、失败数和失败原因。
- CSV 的 `_id` 若是 24 位十六进制，会按 ObjectId 写入；类型推断错误时请先在字段类型中改选。
- 导入只做插入，不做覆盖或 upsert；目标集合已存在相同 `_id` 时会失败。
- 导入进行中不能关闭弹窗，需先停止或等待完成。

#### 导出文档

1. 右键集合或视图，选择“导出”。
2. 选择格式：

   | 格式 | 用途 |
   |---|---|
   | JSON | 一个 JSON 数组，适合整体备份和再次导入 |
   | CSV | 平铺为表格，适合 Excel；会丢失部分类型信息 |
   | JSONL | 每行一篇文档，适合流式处理和大文件 |

3. 选择范围：“全量”导出整个集合；“当前筛选条件”使用集合工作台已生效的过滤、投影和排序。条件在弹框中只读展示，需要修改时回到集合工作台。
4. 选择保存路径后开始导出，可在日志页查看进度并取消。

导出规则：

- “当前筛选条件”会忽略工作台当前的“起始位置”和“返回条数”，按条件分页导出完整结果。
- 先写入临时文件，成功后才改名为目标文件；取消或失败不会留下半截文件。
- CSV 会先收集所有文档的字段并集，再按固定列序写入；嵌套对象和数组会被平铺或转成文本，类型信息可能丢失。
- 导出进行中不能关闭弹窗，需先取消或等待完成。

### 11.9 命令工作台

右键数据库，选择“命令工作台”。工作台以“一条语句一张结果卡片”的方式执行，适合反复调试和回看结果。

1. 在顶部编辑器中输入一条语句，例如：

   ```javascript
   db.customers.find({ city: "上海" }).sort({ created_at: -1 }).limit(20)
   ```

2. 点击运行按钮。每次执行一条语句，不支持一次运行多条语句、`let` 变量或 JavaScript 求值。
3. 结果按执行顺序追加，每张卡片显示成功 / 失败、文档数、结果大小和耗时。
4. 卡片支持折叠、复制完整结果、重新执行和删除；顶部垃圾桶清空全部结果记录。

支持范围：

| 类别 | 语句 |
|---|---|
| 会话 | `use <库>`、`show dbs`、`show collections`、`db.getCollectionNames()` |
| 读取 | `find`、`findOne`、`count` / `countDocuments`、`estimatedDocumentCount`、`distinct`、`aggregate`、`getIndexes`、`stats` |
| 写入 | `insertOne`、`insertMany`、`insert`、`updateOne`、`updateMany`、`replaceOne`、`deleteOne`、`deleteMany`、`remove` |
| 索引与集合 | `createIndex`、`dropIndex`、`dropIndexes`、`drop`、`db.createCollection(...)` |

补充规则：

- 只有 `find` 支持链式 `.sort()`、`.skip()`、`.limit()`。
- 支持 `ObjectId("…")`、`ISODate("…")`、`NumberLong(…)` 等构造器，执行前会转换为 Extended JSON。
- 不支持 `bulkWrite`、`update`、`save`、`renameCollection`、`createIndexes`、`dropDatabase`、`createUser`、`runCommand`、`findOneAndUpdate`、`findOneAndReplace`、`findOneAndDelete`，会给出明确的“不支持”提示。
- `aggregate` 中不能使用 `$out` / `$merge`。
- `use` 只切换当前工作台会话的库，不修改连接配置；工具条上的库名会同步更新。
- 单次查询最多返回 500 篇文档；结果超过 8 MiB 会提前截断并标记“已截断”。
- 结果卡片正文最多展示 64 KiB，点“复制”可取得完整结果；历史最多保留 100 条或 32 MiB，超出后回收最旧记录。

![MongoDB 命令工作台](screenshots/manual/mongo-workbench.png)

> **注意**：白名单内的写方法会立即提交，没有事务包裹，也不能回滚。执行 `updateMany`、`deleteMany` 或 `drop` 前先确认当前库、集合和过滤条件；只读连接会在发送前拒绝写方法，并提示“连接已设为只读，未执行”。

### 11.10 命令行终端

右键数据库，选择“命令行终端”。

1. 终端打开后提示符为 `库名> `，可直接输入一条 shell 语句并回车。
2. `↑` / `↓` 翻阅历史，`Tab` 补全库名、集合名或方法名。
3. `Ctrl+C` 放弃当前输入并换行，`Ctrl+U` 清空当前行，`Ctrl+L` 清屏，`Ctrl+D` 或输入 `exit` / `quit` 结束会话。

![MongoDB Shell](screenshots/manual/mongo-cli.png)

终端与命令工作台共用同一套语句解析和只读边界：

- 支持与工作台相同的读方法、写方法与集合方法，同样不支持 JavaScript 变量和多语句。
- 一次回车执行一条语句，写操作立即生效，没有预览或回滚。
- `use` 切换库后，提示符和补全列表同步更新。
- 只读连接拒绝写方法，返回“连接已设为只读，未执行”。
- 关闭标签页只结束当前终端会话，不会删除数据。

> **注意**：终端按行执行，不能粘贴多行 JavaScript 脚本。需要较长语句时先用文本编辑器整理成一行，或改用命令工作台。

### 11.11 只读与安全边界

- **视图只读**：视图不提供写入类菜单和按钮；文档详情只读。
- **连接只读**：只读连接下集合页隐藏新增、复制文档、删除、导入、重命名和删除集合等写入口；命令工作台与命令行终端在发送前拦截写方法。
- **写操作即时生效**：文档增删改、索引删除、集合删除、Shell 写方法都没有事务回滚。高风险操作前先备份或导出。
- **聚合写阶段受限**：`$out` / `$merge` 不能预览，也不能在命令工作台或终端中执行。
- **凭据保护**：连接密码和含密码的连接串不写入日志、导出、事件或 AI 上下文；截图和文档中同样不要出现明文密码。
- **文档内容边界**：集合页展示的文档内容不会自动进入 AI 上下文；AI 需要读取时按权限走只读工具。

各分区的保存方式不同：

| 分区 | 顶部按钮 | 说明 |
| --- | --- | --- |

### 12.1 编辑器

“编辑器”分区用于调整 SQL 编辑器和结果区行为。

| 设置项 | 可选值 | 说明 |
| --- | --- | --- |
| 字体大小 | 10–24 px 滑块 | 控制 SQL 编辑器文字大小；保存后应用到已打开的查询编辑器 |
| 行高 | 13–28 | 控制 SQL 编辑器每行高度；输入非法值时提示“行高请输入 13-28 的数字” |
| 默认查询限制 | 不限制、100、500、1000 | 查询结果每页默认显示行数 |
| 执行危险 SQL 前弹出确认 | 开 / 关 | 命中危险操作清单时先弹出确认 |
| 危险 SQL 操作清单 | DROP、TRUNCATE、UPDATE 无 WHERE、DELETE 无 WHERE、ALTER TABLE | 勾选哪些语句算危险；前四项默认勾选，ALTER TABLE 默认不勾选 |
| 查询结果默认布局 | 下方、右侧 | 同时作用于 SQL 查询结果和 Redis Workbench 结果区；保存后立即生效 |
| 执行危险命令前弹出确认 | 开 / 关 | 执行 FLUSHDB、FLUSHALL、SHUTDOWN 等 Redis 破坏性命令前先确认 |
| Tab 宽度 | 2、4、8 | 按 Tab 缩进时插入的空格数 |
| 自动换行 | 开 / 关 | 长行是否按窗口宽度换行 |

操作步骤：

1. 调整字体大小滑块，或直接修改行高输入框。
2. 在“默认查询限制”中选择每页行数。选择“不限制”表示不追加默认分页限制，不代表服务端会返回无限行；仍受连接、内存和查询本身限制。
3. 如需对结构变更也弹确认，展开“危险 SQL 操作清单”，勾选 `ALTER TABLE`。
4. 点击右上角“保存”。保存成功后提示“已保存编辑器设置”。

**提示**：点击“恢复默认设置”只把当前分区的草稿恢复为默认值，仍需点击“保存”才会落盘。

“快捷键”分区列出可修改的应用快捷键和查询快捷键：

| 分组 | 操作 | macOS 默认 | Windows / Linux 默认 |
| --- | --- | --- | --- |
| 应用 | 新建查询 | ⌘Y | Ctrl+Y |
| 应用 | 刷新 | ⌘R | Ctrl+R |
| 应用 | 保存 / 应用 | ⌘S | Ctrl+S |
| 应用 | 关闭当前标签页 | ⌘W | Ctrl+W |
| 应用 | 显示 / 隐藏连接侧边栏 | ⌘1 | Ctrl+1 |
| 查询与数据 | 执行 / 应用 | ⌘Enter | Ctrl+Enter |
| 查询与数据 | 搜索数据 | ⌘F | Ctrl+F |

修改步骤：

2. 按下新的组合键。只按修饰键或无法识别的按键时显示“请按下有效快捷键”。

#### 12.8.2 本地 MCP

“本地 MCP”让外部客户端通过本地 stdio 服务使用 FluxDB 的受限能力，不绑定端口，配置保存在本机。

1. “MCP 控制”中打开“启用 MCP Server”。
2. 选择“全局默认策略”：只读或允许读写。该策略不增加连接授权。
3. 在“数据源”中点击“新增数据源”，选择连接并设置该连接为“只读”“允许读写”或“默认（跟随全局）”。未加入的连接不会暴露给外部客户端。
4. 在“客户端接入”中点击“添加客户端”，可写入 Codex CLI 或 Claude Code 的 MCP 配置。也可复制启动命令或 JSON 示例，手动接入其他支持 MCP stdio 的客户端。
5. 需要移除客户端配置时点击“卸载”。

**注意**：“已配置”只表示写入了客户端配置，不代表客户端已经连接；关闭 MCP Server 不会删除客户端配置。外部客户端看到的连接和写入能力仍受数据源策略与安全审计限制。

#### 12.8.3 内置插件

“内置插件”页签列出当前内置插件实例和生效状态，例如当前界面与 @ 上下文、文件与附件、模型路由、Jev 决策优化、上下文压缩、调用前安全审计、AI 用量统计、BI 与报表输出、计划与执行进度、生命周期诊断。

点击插件右侧“管理”打开配置：

- 配置项由插件声明，候选项和校验由 FluxDB 解析。
- 留空通常表示不拦截或不启用该规则。
- 规则变更在下一个工具调用边界生效。
- 安全审计插件可配置禁止访问的表、允许访问的表、只读保护的表、禁止访问的列、禁止结构变更、写操作必须带条件，以及 Redis 禁止命令和 Key 前缀。

#### 12.8.4 安全审计

“安全审计”始终开启且只读，记录工具调用来源、目标、判断（允许 / 需审批 / 拒绝）、命中规则、最终计划、plan hash 和说明。

- 顶部可按判断筛选，也可搜索记录。
- 点击“详情”展开单条审计。
- 审计只追加不修改；参数或目标变化会让旧审计与审批失效。
- 审计无法执行或保存时，操作不会继续。

| 显示 / 隐藏连接侧边栏 | `⌘1` | `Ctrl+1` |
| 执行 / 应用 | `⌘Enter` | `Ctrl+Enter` |
| 搜索数据 | `⌘F` | `Ctrl+F` |
| SQL 历史快速搜索 | `⇧⌘H` | `Ctrl+Shift+H` |
| 快速打开表 | `⌘P` | `Ctrl+P` |
| 复制数据 | `⌘C` | `Ctrl+C` |

各操作的实际行为：

| 操作 | 行为 |
| --- | --- |
| 新建查询 | 按当前连接类型打开 SQL 查询、Redis Workbench 或 MongoDB Shell |
| 刷新 | 按当前页面刷新：对象页刷新对象，数据页重新取数；SQL 编辑器聚焦时改为执行选区或光标所在语句，覆盖全局刷新 |
| 保存 / 应用 | 查询页保存查询；数据页提交待处理修改；设置页保存整个设置草稿 |
| 关闭当前标签页 | 关闭当前活动标签页；新建连接未完成时先取消新建 |
| 显示 / 隐藏连接侧边栏 | 切换左侧连接浏览区 |
| 执行 / 应用 | 查询页执行选中语句，未选中时执行光标所在语句；数据页提交修改；建表页添加一行；MongoDB 文档分节执行查询 |
| 搜索数据 | 打开当前数据页的搜索面板 |
| SQL 历史快速搜索 | 打开 SQL 历史并快速筛选、复用 |
| 快速打开表 | 搜索当前数据库中的表并打开 |
| 复制数据 | 优先复制界面中已选中的文字；没有文字选区时复制数据页中选中的表格数据 |

**注意**：SQL 编辑器聚焦时，`⌘R` / `Ctrl+R` 被编辑器内的 Run 绑定接管，执行选区；没有选区时执行光标所在语句。此时它不会刷新对象树或数据页。要刷新连接树，先点一下编辑器外的区域，或使用自定义的刷新快捷键。

### 13.2 固定快捷键

| 操作 | 快捷键 | 说明 |

**提示**：如果自定义快捷键与系统或其他应用冲突，应用内可能录制成功但系统先截获按键。此时换一个组合键，或在系统设置中调整冲突项。

## 14. 常见问题

### 14.1 连接测试失败

按以下顺序检查：

1. 数据库服务是否已启动并监听填写的地址和端口。
2. 主机和端口是否能从当前机器访问。
3. 用户名、密码、数据库名、Schema 或认证库是否正确。
4. 数据库账号是否允许来自当前地址的连接。
5. TLS 模式、证书、SNI 或客户端证书是否与服务端要求一致。
6. SSH 跳板机是否可登录，认证方式和目标地址是否正确。
7. 云数据库安全组、防火墙或 VPN 是否放行。
8. MongoDB 检查连接串、认证库和认证机制；Redis 检查集群、哨兵或代理拓扑。

### 14.2 连接成功但看不到数据库或表

- 右键连接或数据库选择“刷新”。
- 右键连接选择“选择显示数据库”，检查目标数据库是否被隐藏。
- PostgreSQL 检查默认 Schema 和“显示系统 Schema”设置。
- MongoDB 检查当前数据库和集合筛选条件。
- 确认账号拥有读取元数据和目标对象的权限。

### 14.3 查询可以运行，但结果不能编辑

结果编辑需要能够可靠识别源表和记录。连接查询、多表查询、聚合结果、缺少主键或唯一标识的结果可能只读。可双击原始表打开数据页后再尝试编辑。

MongoDB 的结果区按文档或表格展示；只读连接和只读集合会禁用写入入口。

### 14.4 修改了数据但数据库没有变化

表格编辑先保存在本地待提交区。查看底部是否有“待提交 N 处修改”的提示，确认后点击“提交更改”。

点击“取消更改”、刷新或关闭页面会放弃尚未提交的修改。提交前可先查看“待提交 SQL”并复制留档。

### 14.5 备份按钮不可用或备份失败

- 新建备份弹框要求填写目标目录；输入留空时回退到设置中的 `backup_dir`（默认是可执行文件目录下的 `backup`），两者都为空会阻止开始。目录不存在时先创建，或换一个有写权限的目录。
- 检查目录是否存在，当前用户是否有写权限，磁盘空间是否足够。
- PostgreSQL / MySQL 等原生转储依赖对应客户端工具。在“设置” → “数据”中检测 `pg_dump` / `mysqldump`，或确保工具在系统 PATH 中。
- 查看备份窗口的实时日志和阶段信息。
- 备份方式由应用按数据库类型和可用工具自动选择，不能手动切换原生或逻辑方式。
- 原生工具版本尽量与数据库服务端主版本兼容；版本不匹配时换用与服务端匹配的客户端。
- SQLite 备份使用完整一致性快照，不能按对象或只选结构/数据。

### 14.6 PostgreSQL 或 MySQL 客户端未找到

- 展开“设置” → “数据”中的对应客户端分组，点击“检测”查看版本、路径和缺失工具。
- PostgreSQL 常见缺失工具为 `pg_restore`、`psql`；MySQL 检测依赖 `mysqldump`。
- 当前平台提供下载按钮时，可点击“下载并安装”获取客户端；也可以指定本机安装目录。
- 也可以先在系统中安装客户端并确保其 `bin` 目录在 PATH 中，再重新检测。
- 检测顺序为：客户端目录 → 应用下载目录 → 系统安装路径 → PATH。

**注意**：当前版本“数据”页顶部保存按钮不可用，手动选择的路径不会持久化。优先让工具进入系统 PATH，或通过检测确认当前会话可用。

### 14.7 Redis 搜索不到 Key

- 确认当前逻辑数据库编号正确。
- 清空搜索条件后刷新。
- 检查 Key 模式是否过于严格。
- 确认账号具备 SCAN 和读取相关数据类型的权限。
- 集群、哨兵或代理环境下，检查连接拓扑配置是否正确。
- 只读连接不会阻止浏览，但会阻止修改和删除。

### 14.8 MongoDB 写入被拒绝

- 检查连接是否启用“只读”。
- 聚合中的 `$out` / `$merge` 不允许预览或执行。
- 命令工作台和命令行终端只接受受支持的方法；`bulkWrite`、`findOneAndUpdate`、`renameCollection`、`createUser` 等未支持方法会被拒绝。
- 集合只读或权限不足时，文档编辑、导入、索引修改和删除集合不可用。
- 写入没有事务回滚，执行前先确认集合、筛选条件和文档范围。

### 14.9 AI 模型不可用

- 打开“设置” → “大模型”，查看模型的凭据状态和连接状态。
- 凭据为“缺少凭据”时编辑模型并填入 API Key；编辑时留空会保留原 Key。
- 模型被停用、禁止出站，或不是所需能力类型时，Agent 无法使用它。
- 点击“测试连接”确认端点、模型 ID 和密钥可用。
- “决策”模型不能设为默认主模型；默认主模型只能从生成模型中选择。

### 14.10 应用操作后界面没有更新

先等待当前 loading 状态结束，再刷新当前对象。不要在备份、导出、SQL 文件执行或大查询仍在运行时反复点击相同操作。

如果操作已发出但连接中断或应用退出，不要直接重放写入。先重新连接，核对事务、数据页或审计记录，确认结果后再决定是否重试。

## 15. 数据安全建议

### 15.1 连接与凭据

- 为生产环境连接使用醒目名称并单独分组，避免误连测试库或生产库。
- 日常浏览优先使用只读账号；只在确需写入时使用写权限账号。“只读连接”开关是客户端拦截，不能替代数据库侧的只读账号。
- 连接密码以 AES 密文存入 SQLite，不保存明文；模型 API Key 也走加密存储。
- 不要把密码、API Key、私钥、证书、连接串或含密码的导出文件提交到 Git、工单或聊天工具。
- 日志、诊断导出、事件和 AI 上下文不包含密码明文；截图和排障材料同样要遮挡敏感信息。

### 15.2 危险操作

- 执行 `UPDATE`、`DELETE`、`TRUNCATE`、`DROP`、`ALTER TABLE` 前，确认连接、数据库、Schema 和条件范围。
- 保持“执行危险 SQL 前弹出确认”开启，并按需把 `ALTER TABLE` 加入危险操作清单。
- 表格批量修改前查看“待提交 SQL”；条件不明确时取消更改。
- Redis 保持危险命令确认开启；执行 `FLUSHDB`、`FLUSHALL`、`SHUTDOWN` 前确认目标实例和库号。
- MongoDB 文档增删改、索引删除、集合删除和 Shell 写方法没有事务回滚；先导出或备份。
- 结构变更、权限变更和批量导入前先备份，并实际验证备份可恢复。

### 15.3 AI 与 MCP 边界

- AI 工具默认策略按需选择“只读”“写审批”“帮我审批”或“自动执行”。自动执行会跳过逐次确认，只应在明确授权范围内使用。
- 全局关闭的工具对所有 Agent 生效；Agent 只能使用已启用且被授权的工具。
- “本地 MCP”只向外部客户端暴露已加入的数据源；未加入的连接不可见。每个数据源单独设置只读、允许读写或跟随全局。
- “已配置”客户端只表示写入了客户端配置，不代表已连接；不再使用时点击“卸载”移除配置。
- 安全审计始终开启且只读。审计失败或无法保存时，操作不会继续。
- 当前页面内容不会自动全部进入 AI 上下文；业务数据按有界只读工具读取，敏感配置禁止进入上下文。

### 15.4 数据与恢复

- 导出前确认范围是全量还是当前筛选条件。MongoDB 导出选择“当前筛选条件”时会忽略分页的 skip/limit。
- 备份文件按数据库和业务重要性分层保存，定期做恢复演练，而不是只确认备份文件存在。
- 导入前先用预览确认字段映射、类型和冲突处理；批量导入失败时先看已写入批次，不要直接重复导入。
- 查询被取消、应用异常退出或网络中断后，重新连接并核对事务和数据状态。界面显示“结果未知”时，先只读核实，不要重放同一写入。
- 删除已归档会话前确认影响范围；删除后消息、审计事实和产物快照不可恢复。
