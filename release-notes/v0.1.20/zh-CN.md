## 新功能

- 结构同步与数据同步能力补齐：新增同步编排、分块预览与流式执行，支持跨类型建表与类型映射；结构同步覆盖 CHECK 约束、外键引用动作、索引类型 / predicate 与生成列，SQLite 支持原生索引建删；任务中心接入同步任务并可查看执行记录。同步向导的表清单默认不勾选，预览或执行前必须显式选择。
- 数据同步支持导出迁移 SQL、跨库写入会话与断点续传：语句执行成功后才追加落盘，默认文件名带表名与本地时间，追加模式逐条刷新且不重复文件头；补齐插入冲突模式、行级失败策略与 LOB 摘要；同步账本新增续传签名、块游标值与失败行记录（存储迁移 v5）。
- 数据库备份与恢复增强：新增 MongoDB 原生归档备份 / 恢复（`mongodump` / `mongorestore`），凭据通过临时 0600 配置文件传递，不在命令行或日志中暴露；新增 PostgreSQL 逻辑备份；MySQL / PostgreSQL 逻辑备份改为 keyset 游标分页与多行 `INSERT` 批量写入，并建立一致性快照。恢复弹框支持 MongoDB，备份列表的路径列支持点击复制完整路径。
- 复制数据支持附带列名：新增 `⌘⇧C` / `Ctrl+Shift+C`，选区右键菜单同步提供「复制选区（含列名）」；单元格选区只输出选中列的列名，行号列不参与。
- 表注释可用于浏览与检索：侧边栏表行悬停展示表名与注释，对象搜索同时匹配表名和注释；快速打开表（`⌘P`）与命令面板支持按注释召回，并在候选副标题中展示。
- 数据同步完成后展示独立状态：新增成功 / 部分失败 / 已取消状态条，展示表数与增删改统计；消息日志保留执行期进度并追加报告摘要；完成后主按钮改为「完成」并关闭向导。
- 统一数据库品牌图标样式：侧边栏连接图标改为跟随主题的圆角底板与细边框，首页最近连接、新建查询弹窗和新建连接类型列表同步；品牌 logo 统一放大，缓解各图标留白差异。
- 结构对比增加加载态：对比进行中显示「对比中…」和转圈，不再显示旧结果或空态；Schema 选择仅对 PostgreSQL / KingbaseES / SQL Server / Oracle / 达梦 展示，MySQL / MariaDB / TiDB / SQLite 隐藏该字段。

## 改进

- 连接列表光标改为手型，不再显示握紧的手。
- 备份列表路径列增加悬停提示与复制成功提示。
- 大数据量导出与备份采用分批读取，避免一次性加载整表。

## 修复

- 修复 SQL Server 展开对象树固定报 207 的问题：表大小改从 `sys.dm_db_partition_stats` 读取 `used_page_count` 与 `row_count`；低权限账号缺少 `VIEW DATABASE PERFORMANCE STATE` 时回退为不带大小的查询，对象树仍可正常展开。
- 修复 MySQL 9.x `mysqldump` 不接受 `--connect-timeout` 导致备份在参数解析阶段失败的问题；该参数只传给恢复导入的 `mysql` 客户端。
- 修复编辑连接时无法关闭只读：保存前先移除旧的 `read_only` 选项再合并草稿。
- 修复 MySQL 侧边栏表体积显示旧值：列对象前关闭 `information_schema` 的 24 小时统计缓存；统计仍取决于 InnoDB 自身刷新，必要时可执行 `ANALYZE TABLE`。
- 修复 Redis 键类型随值内容变化：普通 STRING 即使存 JSON 文本也仍显示 STRING，只有真实 ReJSON 键显示 JSON；JSON 查看态长值可纵向滚动看全，解析失败回退展示当前值。
- 修复服务端未安装 RedisJSON 模块时选择 JSON 创建会静默存成普通 string 的问题，现在明确报错并提示安装模块。
- 修复新增 Key 与编辑值的输入框只有点击文本区域才能聚焦，点击框内任意位置即可输入；String 值切换 JSON 格式后使用带语法高亮的只读视图。

## 已知限制

- 逻辑备份不导出存储过程 / 函数、触发器、事件、权限与序列当前值，恢复后需手工补齐；大字段无法读取时直接报错，不生成半成品。
- MongoDB 归档只支持单库整库导出，不支持按集合选择；未使用 `--oplog`，一致性标记固定为否。恢复依赖备份记录中的原始库名，外部归档当前会被拒绝。
- Oracle / SQL Server / 达梦尚无一致性快照，逻辑备份会显式标记为非一致快照。
- 结构 / 数据同步与备份恢复均依赖对应数据库客户端工具；缺少工具时会在准备阶段明确提示，不会静默降级。
