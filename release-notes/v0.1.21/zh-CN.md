## 修复

- 修复 Redis 键类型随值内容变化的问题：普通 STRING 即使存的是 JSON 文本也仍显示 STRING，真实 JSON 键（ReJSON）才显示 JSON。
- 修复 Redis JSON 查看态长值被截断：内容超出面板时可纵向滚动，无需进入编辑态即可看全。
- 修复 Redis JSON 内容解析失败时展示残留上一个键值的问题，改为回退展示当前键的原始文本。
- 修复服务端未安装 RedisJSON 模块时选择 JSON 创建会静默存成普通 string 的问题：现在明确报错并提示安装模块，不再产生「选 JSON 却显示 STRING」的键。
- 修复新增 Key 与编辑值的输入框只有点击文本区域才能聚焦的问题，点击框内任意位置都可以直接输入。

## 改进

- String 值切换到 JSON 格式时使用带语法高亮、行号与层级缩进的只读视图；非法 JSON 自动回退为原始文本。
