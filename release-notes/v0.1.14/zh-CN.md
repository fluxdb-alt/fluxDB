## 新功能

- 新增 MongoDB 数据源：连接串导入（`mongodb://` / `mongodb+srv://`）回填主机、SRV、账号、默认库与认证库，连接后按「连接 → 库 → 集合分组 → 集合 / 视图」浏览。
- MongoDB 集合工作台分四个页签：文档、聚合、索引、信息。文档页支持筛选、投影、排序、排序规则、起始位置、返回条数、执行上限与索引提示，结果可在卡片 / 表格 / JSON 三种展示方式之间切换。
- 查询面板提供条件构建器：图形化条件实时写回同一份 Filter 文本，支持等于 / 不等于 / 大于 / 大于等于 / 小于 / 小于等于 / 包含任一 / 字段存在，最多 6 行 AND 条件；反向解析接受 Compass 风格的宽松 JSON（无引号键、单引号、注释、尾逗号）。
- Filter / 投影 / 排序与聚合管道接入补全：按括号栈与字符串状态判定键位、值位与字段引用，键位补字段路径与查询运算符，字符串内按字段补真实取值，值位补 Extended JSON 构造器模板。
- 文档写入：新增、整篇替换编辑、复制为新文档、单篇删除。四处入口共用右侧抽屉与同一套 JSON 编辑器，`_id` 不可修改，未保存草稿的隐式切换会先确认。
- 文档导入支持 JSON 数组、JSON Lines 与 CSV，按内容嗅探格式；CSV 逐列扫描整份文件推断类型，混类型列按 mixed 逐格嗅探，可在导入前逐字段改选。按 1000 条一批写入，支持中止与消息日志。
- 文档导出支持 JSON / JSONL / CSV 与「全量 / 当前筛选条件」两种范围，条件导出按 Compass 风格展示只读查询预览；先写 `.partial` 再改名，取消或失败不留半截文件。
- 集合右键菜单：置顶、复制名称、刷新、导出、重命名、导入、删除；视图只读，不渲染写入入口。库右键新增创建集合与删除数据库，连接右键新增查看连接信息（拓扑、版本、主机列表、可见数据库）与命令行终端。
- MongoDB 接入 AI 页面上下文与受控执行：只暴露定位、查询条件与状态，文档值经有界只读工具按需读取。

## 改进

- 超大字段不再导致整行丢失：单元格正文超出结果页预算时外置到本地受控存储（单归属 256 MiB、进程合计 1 GiB，关闭标签 / 翻页 / 断开即清理），结果里只保留预览与完整大小，可在单元格详情中按 256 KiB 分块只读查看。MySQL、SQLite、PostgreSQL、SQL Server 与达梦 DM8 统一接入。
- 大字段上传替换改为分块流式追加（≥16 MiB 走暂存 + 追加），大文本列同样提供上传入口；占位值是预览值，复制 / 导出 / 编辑 / AI 上下文按「只是预览」拒绝，避免把截断内容当真值写回。
- MongoDB 文档区改用虚拟列表并缓存整页解析结果，逐帧只构建视口内的卡片；表格与 JSON 视图共用同一套行虚拟化，折叠与展开后按需重排。
- MongoDB 查询面板「更多选项」与「高级查询」两层收起时以角标提示仍在生效的条件数，展开态按标签页记忆。
- 筛选 / 排序弹层改为按点击点锚定，控件换行、滚动或面板变高后仍贴在触发控件旁，且不会越出窗口。
- 执行摘要超出面板高度时可纵向滚动，批量执行行数多时不再只能看到被裁掉的前几行。

## 修复

- 修复 PostgreSQL 含大字段的行无法更新 / 删除，以及数组列（如 `numeric(12,4)[]`）导入时类型不兼容的问题。
- 修复无主键表中含大字段的行身份无法确定时静默产生 0 行影响的问题，现统一拒绝并说明原因。
- 修复 SQL Server 结果超出预算时直接丢弃整行的问题，改为先把大字段外置成内容引用再收行；同时修正翻页 SQL 对外层列名的引用。
- 修复达梦 DM8 只按行数截断结果页的问题，改为按字节预算收页并外置单格超大值。
- 修复 MongoDB 导入非 ASCII 值时的崩溃（日期嗅探按字节比较前缀，不再切在 UTF-8 字符中间）。
- 修复 MongoDB 创建集合后侧边栏不显示新集合，需要手动刷新的问题。
- 修复 MongoDB CSV 导入按多数类型定型导致少数派行整条失败的问题，改为混类型列逐格嗅探。

## 已知限制

- MongoDB 不提供数据库级备份恢复（`mongodump` / `mongorestore`），导出是文档级逻辑导出；「查看性能指标」置灰未实现。
- MongoDB 不支持 SSH 隧道；TLS 相关参数经连接串导入，TLS 页签对 MongoDB 不提供表单。
- MongoDB 单次查询最多返回 500 篇文档；导出按 `skip` 翻页，集合在导出期间被并发修改时可能漏读或重复。
- MongoDB 不支持批量删除（删除后立即重查，无撤销）、跨库移动集合、视图重命名 / 删除、时间序列与 capped 集合的创建入口、表格行内编辑、事务与变更流。
- MongoDB CSV 导入只支持标量字段（嵌套对象 / 数组请走 JSON 路径），文件必须是 UTF-8；新增文档的 `_id` 固定为 ObjectId，不支持改成其它类型。
