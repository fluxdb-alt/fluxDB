## 新功能

- 新增结构对比与同步：从连接右键菜单进入，选择源端与目标端的连接、数据库及可选 Schema / 表，按 `schema.name` 配对基础表，展示目标缺失、目标多出、结构不同与一致四种状态，并提供两端 DDL 对照及字段 / 索引差异明细；可按勾选执行新建缺失表、删除目标多出表、重建结构不同表，同步在后台运行并写入任务中心。
- 新增跨连接数据传输：把源表数据分页读取、分批写入另一连接的目标表；支持追加写入与清空后写入，目标表不存在时可按源端 DDL 自动建表；进度与运行日志实时展示，可取消，内存占用只与单页行数相关，不随表大小增长。
- 新增任务中心：汇总备份、恢复、SQL 文件执行、表导入导出、Mongo 导入导出、结构同步与数据传输等后台任务，统一展示运行中 / 已完成 / 失败 / 已取消状态、进度与日志，支持取消，并把历史记录持久化到本地，重启后仍可查看。
- 新增可视化执行计划：工具栏「解释」复用当前选区 SQL，解析 MySQL / MariaDB / TiDB 的 `EXPLAIN FORMAT=JSON`、PostgreSQL / KingbaseES 的 `EXPLAIN (FORMAT JSON)`、SQLite 的 `EXPLAIN QUERY PLAN` 以及手写的 MySQL 风格 `EXPLAIN` 表格，生成节点树与节点检查器，并标记全表扫描、文件排序、无索引等风险；无法解析时保留原始结果表格，不猜测计划结构。

## 改进

- 重构新建连接表单（上一版本遗漏说明）：高频字段保留在「连接信息」，MySQL / MariaDB / TiDB 的字符集、排序规则与 URL 参数移入「高级」；SQLite 隐藏空的网络页签，减少无效填写。
- MySQL / MariaDB / TiDB 新增 SOCKS5 与 HTTP CONNECT 代理，均支持用户名密码认证，可与 TLS 组合使用；PostgreSQL 复用共享代理拨号。代理不可达、握手失败或认证失败直接报错，不静默回退直连；SSH 隧道与代理互斥。
- 统一各数据库连接档案的校验、options 回写、拨号端点与凭据槽位，集中管理表单字段与档案回填，减少新增数据源时的重复分支。

## 修复

- 修复 MySQL 旧连接档案的 TLS 模式迁移误判：仅在 TLS 启用时把旧 verify 位迁移为 `verify_ca`，TLS 关闭的旧档案不再被误改。
- 修复「筛选 & 排序」切换字段时无条件清空已填值：改为按新列类型判断，文本 / 未知类型原样保留，数字 / 布尔列只保留能解析的值；介于 / 不介于任一上下界不兼容时整体清空，部分值被移除时提示数量。
- 修复 PostgreSQL 补全在 KingbaseES 上的兼容性问题，以及导出分页中嵌套 `block_on` 的问题。
- 补齐备份与恢复「取消任务」的中英文文案，修复语言包缺键。

## 已知限制

- 结构对比只比较基础表，不比较视图与例程；跨数据库类型同步按源端 DDL 重建，目标端不支持的语法需要手工调整。
- 数据传输选择「清空后写入」时，清空与后续批次写入不在同一事务内，中途失败会留下已清空的目标表。
- 执行计划只解析 MySQL / MariaDB / TiDB、PostgreSQL / KingbaseES 与 SQLite 的输出，其他数据库或无法识别的格式回退为原始结果表格；「解释」入口不会执行 `EXPLAIN ANALYZE`。
- 任务中心历史记录保存在本地；进程中断时仍在运行的任务会按失败记录。
