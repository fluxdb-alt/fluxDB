## 新功能

- 查询结果支持全选复制与导出：数据页和查询结果页可用 `⌘A` / `Ctrl+A` 选中当前页全部单元格，复制为 TSV 直接粘贴到 Excel（焦点在搜索框或 SQL 编辑器时仍为全选文本）。查询结果工具栏新增「导出」，条件默认沿用结果实际执行的 SQL，可在「条件」页签修改后刷新估算；「常规」页签可选择字段（默认全选、可反选）并输出 TXT / CSV / JSON / XML，重名列按 `id`、`id_2` 去重表头；导出按 SQL 全量执行、分批读取，不受结果页分页限制，支持取消。
- 新增测试数据生成器：表数据页工具栏「数据生成」或表右键菜单「生成测试数据」打开弹窗。按列配置生成器与参数，内置数值、文本、姓名、联系方式、地址、公司、电商、日期等 40+ 生成器，并按列类型灰掉不兼容项；外键列读取父表取值池（物理外键与 ER 逻辑关系合并，最多 1000 行），预览与真实写入共用同一套取值规则。可设置行数（上限 200000）、随机种子、数据语言、每列 NULL 比例与唯一限制、批次大小（1–5000），写入方式支持「追加」与「清空后写入」，唯一冲突可选「跳过该行」或「终止」；右侧提供数据预览、目标方言 SQL 示例与任务日志，运行中可取消。
- 新增查询编辑器分屏：同一标签内可任意左右 / 上下分屏，每屏独立编辑、运行与结果。`⌘\` / `Ctrl+\` 左右分屏，`⇧⌘\` / `Ctrl+Shift+\` 上下分屏；关闭仍有 SQL 或结果的分屏时选择丢弃或移到新标签；标签条显示当前标签的屏数徽标。
- 新增外键导航、关系面板与表单视图：数据工具栏新增「表格 | 表单」切换，表单纵向排布字段并复用同一 `EditDataCell` 改动集与提交语义；外键单元格与右侧关系面板支持等值跳转到父行 / 子行，面板含内联预览、ER 迷你图与宽度拖拽；枚举 / 候选值列在表单中提供可输入下拉。
- 新增统一命令面板：`⇧⌘P` / `Ctrl+Shift+P` 打开，一次搜索命令、对象、查询、历史与连接，`Tab` / `Shift+Tab` 切换范围，方向键选择、`Enter` 执行，命令项右侧显示自身快捷键。
- 新增标签页快捷切换：`Ctrl+Tab` / `Ctrl+Shift+Tab` 按住打开 VS Code 式标签抽屉并连续切换，松开提交；`⇧⌘E` / `Ctrl+Shift+E` 打开可搜索切换器；选中项超出可视区时自动滚动。切换范围限当前连接 / 数据库工作区。
- 新增标签编号直达与表快捷组：`⌥1`–`⌥9` / `Alt+1`–`Alt+9` 按编号切换当前工作区可见标签页（顺序含置顶与拖拽）。一个快捷键可绑定 1–9 张表，单表直接打开，多表弹出键盘选择器；最多 32 个快捷组。表右键与设置页统一管理，冲突检测覆盖应用快捷键、已有快捷组与保留键位；连接未打开时选择后自动连接并继续打开表。
- 侧边栏显示表占用大小：对象列表随一次元数据查询返回大小，MySQL / MariaDB / TiDB 取数据与索引长度，PostgreSQL / KingbaseES 用 `pg_class.relpages` 与索引页数估算，SQL Server 取 `sys.partitions.used_page_count`；侧边栏宽度不小于 220px 时显示在表名右侧，过窄自动隐藏。

## 改进

- 新增内置 Flux Amber 主题，可在主题选择器中直接切换。
- 查询结果导出会还原用户原始 SQL：执行器自动追加或封顶的默认行数不会写进导出条件，用户未写 `LIMIT` 就不带，写了则保留原值。
- 数据生成器的外键目标以「FK → 表.列」徽章标注，名称过长时中间省略，悬停可查看完整目标。

## 修复

- 修复应用启动时 SQL 历史加载任务被取消、导致历史记录丢失的问题。
- 修复历史表名提取把 `3d_active_history` 等以数字开头的表误判为纯数值 token 而漏记的问题。
- 修复 SQL 历史快速搜索（`⌘⇧H` / `Ctrl+Shift+H`）跨库返回结果的问题，改为按当前连接与数据库过滤。

## 已知限制

- 查询结果导出不提供 SQL INSERT 格式（结果集没有目标表）；导出在只读模式下执行，写语句不会生效；任务中断会留下 `.partial` 临时文件。
- 测试数据生成仅支持 SQL 连接，MongoDB / Redis 没有入口；单次最多生成 200000 行，同一时间只能运行一个生成任务；「清空后写入」只有 PostgreSQL / SQLite 可回滚，其他数据库清空后不可回滚；唯一冲突默认跳过无法生成唯一值的行。
- 表大小只用于侧边栏量级提示：PostgreSQL / KingbaseES 为 `relpages` 估算，未 ANALYZE 或空表可能为 0 而不显示；其余数据库不提供。
- 命令面板、标签切换与编号直达只在当前连接工作区内生效。
- 分屏是标签内部状态，关闭标签时随标签一起丢弃。
